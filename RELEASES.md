## Current: 0.18.9

Патч поверх **0.18.8**. Веб-версия **0.18.9**; существующие нативные установщики не пересобирались.

- Исправлена область видимости фонового обновления календарных категорий чатов. Восстановлено открытие скрытой боковой панели на ПК; на мобильных кнопка переключает панель и доступность её элементов.
- Компактные уведомления закрываются отдельной кнопкой. Повторные ошибки сети не маскируются посторонними успешными фоновыми запросами.
- Настройки имеют резервную копию с привязкой к аккаунту. Неудачное сетевое распознавание не сохраняет принудительный офлайн-режим навсегда; добавлено завершение локальной диктовки с запросом финального результата и быстрый повторный запуск.
- Увеличены согласованные границы сообщений, текстовых исходников и создаваемых файлов. Крупные чаты и исходники сохраняются составными записями с проверкой хеша, вместо ошибки лимита одного документа Firestore. Поддерживаются проекты ZIP до 4 МБ, один исходный файл до 1 МБ и сообщение до 1 000 000 символов; это защитные технические границы, не обещание безлимитного контекста модели. Длинный ответ при подтверждённом finish_reason=length продолжается до трёх раз в рамках общего срока запроса, без потери последнего фрагмента. Оборванный вызов инструмента не исполняется.
- Явный исходный код без разметки в режиме программирования нормализуется в блок кода и реальное вложение. Один файл сохраняет код и скачивание; несколько файлов собираются существующим механизмом ZIP. Добавлены Lua/Luau для выдачи исходников.
- Контекст из других сохранённых чатов подбирается ограниченно и только при включённой сохранённой настройке памяти, в пределах текущего аккаунта. Это не безграничная память и не чтение всех вложений.
- Улучшена читабельность ответов; расширено использование иллюстраций презентации, исправлен статус настроенной SMTP-почты. Требование вежливого ответа усилено.
- Сохранены проверки путей, приватных файлов, безопасности, владельца данных и технические границы защиты от перегрузки. Возможности и квоты провайдеров не снимаются патчем; качество генерации и работа микрофона зависят от модели, браузера, разрешений и устройства.

## Current: 0.18.8

Патч поверх **0.18.7**. Веб-версия **0.18.8**; нативные установщики не пересобирались.

- Файловый диалог принимает произвольные расширения. Неизвестные двоичные форматы сохраняются и скачиваются без запуска, но не выдаются за прочитанные. Лимиты прежние: обычный файл 2 МБ, поддерживаемое фото 25 МБ; видео до 100 МБ анализируется выборкой кадров в браузере, не полным оригиналом или звуком.
- Добавлено ограниченное извлечение текста из PPTX, XLSX, ODT/ODS/ODP и EPUB. Поддерживаемые неизвестные текстовые расширения определяются безопасным декодированием. В XLSX разрешаются общие строки; формулы не пересчитываются, числовые/датовые форматы могут оставаться исходными значениями. PDF/DOCX теперь сохраняют исходные байты вместо подмены текстовым файлом.
- Инструмент `edit_attached_file` по явному запросу создаёт отдельную копию: точные замены в полном доступном тексте либо текстовых узлах DOCX/PPTX/XLSX, включая ранее созданные ИИ документы. Остальные ZIP-части сохраняются; исходник не перезаписывается. Это не произвольное бинарное редактирование, не изменение макросов/подписей, не рендеринг Office и не редактирование PDF без потерь. Выходной Office ZIP ограничен существующим лимитом вложений 500 КБ.
- Добавлен приватный текстовый предпросмотр с отменой запроса при закрытии/смене аккаунта. Неизвестный бинарный файл не декодируется в «читаемый» текст; скачивание сохраняет байты и имя. Исполняемые файлы не запускаются, архивные ограничения безопасности сохранены.
- Большие исходные файлы делятся на ограниченные части в существующем Firestore с проверкой целостности; текстовый предпросмотр не скачивает части. В локальном каталоге проектов не загружаются неиспользуемые base64-данные; полные байты запрашиваются по необходимости. При сбое пакетного сохранения уже сохранённые вложения пакета удаляются.
- Общие календарные категории для чатов и заметок: сегодня, вчера, эта неделя, прошлая неделя, этот месяц, более ранние месяцы с годом. Границы вычисляются по местному календарю, категории обновляются после смены дня. Исправлено ложное распознавание «прочитай файл» как чтения одноимённого текущего чата.
- Компактнее карточки файлов и круг разворачивания сообщения; добавлены размеры и тип файла. Улучшена читабельность публичного журнала работы. История сохраняет реальные этапы, метаданные файлов и размеры после перезагрузки.
- Дополнены регрессионные тесты. Качество ответа по-прежнему зависит от модели; список этапов не является скрытыми рассуждениями или доказательством выполнения тестов. Неподдерживаемые форматы, неполное извлечение, ограничения почты/push и провайдеров сообщаются честно. Новые ключи, переменные Render и зависимости не требуются.

## 0.18.6

- One complete code file is delivered with a download and its code block. Multiple source files are staged and delivered as one ZIP preserving their paths; source dumps are removed from the final project response.
- Static syntax, dependency and local-reference findings are exposed honestly. Up to two final-answer repair attempts are allowed before refusing invalid attachments. Generated code, builds and runtime tests are never executed by this server.
- Project requests use task-aware model routing and a separate bounded 180-second default deadline (`AI_PROJECT_TOTAL_MS`); ordinary chat retains its shorter budget. There are no separate billable availability probes.
- Concrete unfamiliar app purposes no longer trigger a platform/style questionnaire. Image edits preserve successive requested changes; prompt translation checks named subjects, explicit numeric counts and quoted visible text and briefly caches exact translations.
- Reminder delivery retains per-channel and per-device results, retries transient failures up to eight times with backoff, and recovers recent missed configuration/verification and legacy retry states. The UI can fetch schedules without waiting for SMTP; allowed push subscriptions are repaired automatically.
- Streaming Markdown parsing and line measurements are coalesced; unchanged answers and closed journals are not rebuilt needlessly. Low-resource devices use less expensive visual effects without overriding reduced-motion preferences. Frame rate still depends on device load and browser.
- Delivery on time still requires a running server, persistent schedule/VAPID storage, working mail transport and notification permission/device support. Free hosting sleep, missing credentials or denied OS notifications cannot be fixed by a UI patch. No real provider keys or user data are bundled.
