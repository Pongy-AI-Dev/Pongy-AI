# Умный ПК — предварительная версия 0.27.0

Это дополнение к исходникам 0.27.0 после патча session-skill-ci. Не полный автономный агент и не готовый публичный выпуск установщика.

## Что добавлено

- В приложении Windows: кнопка «Умный ПК», описание, цена, подключение и открытие компактного окна у правого нижнего края. Значок в системном трее открывает это окно; закрытие окна останавливает его микрофон, но не завершает основное приложение.
- Неактивный серый маскот, активация нажатием или поддерживаемым зовом, возврат в ожидание после ответа. При первом включении прослушивания нужны разрешение микрофона и согласие пользователя. Сохранённое согласие на прослушивание относится к текущему аккаунту. Обычный голосовой режим при открытии панели отключается, чтобы два распознавателя не конкурировали.
- Подтверждение управления компьютером в отдельном системном окне. «Стоп» в панели, пункт остановки в трее и Ctrl+Alt+Pause отменяют ещё не исполненную команду и снимают разрешение. Остановка не закрывает уже открытые сторонние программы и не отменяет выполненные действия.
- Реальные ограниченные команды: открыть YouTube, Проводник, Блокнот, Калькулятор и зарегистрированный MAX (иначе Web MAX); изменить/выключить звук; изменить яркость поддерживаемого встроенного дисплея через WMI. На неподдерживаемом дисплее возвращается ошибка, а не фиктивное выполнение.
- Обычные вопросы передаются существующему чату. Используются имеющиеся голоса устройства. Новая облачная озвучка и новая модель распознавания не добавлены.
- В разделе разработчика: «Выдача продукта», Plus / Smart PC, почта существующего аккаунта, срок 7 дней / месяц / 3 месяца / год / своя дата, выдача и отзыв. Доступ проверяет сервер, не клиентская галочка. Изменения видны при следующем обновлении состояния (обычно до 15 секунд).
- Истечение Smart PC останавливает распознавание и блокирует команды. Остаются уведомление и продление; Plus и Smart PC независимы.

## Цена и оплата

Smart PC стоит **50 RUB за календарный месяц** при русском языке. При английском языке — USD: 50 RUB / курс USD, затем округление вверх до ближайшего чётного целого числа долларов, минимум $2. Например, при 90 RUB/USD цена $2, при 20 RUB/USD — $4. Цена заказа фиксируется сервером. Смена языка не меняет уже созданный заказ.

Это покупка доступа на месяц, **без автоматического списания**. При продлении новый месяц добавляется к действующему сроку; если срок закончился — отсчёт от оплаты. Конец месяца ограничивается последним днём следующего месяца.

Платежи выключены по умолчанию. Для реальной работы нужны рабочие договор/аккаунт и ключи провайдера:

```dotenv
BILLING_ENABLED=true
YOOKASSA_SHOP_ID=
YOOKASSA_SECRET_KEY=
STRIPE_SECRET_KEY=
# Необязательный ручной курс, RUB за 1 USD:
USD_RUB_RATE=
```

- RUB — YooKassa, USD — Stripe. Доступность валют, страны, чеков и требований к продавцу необходимо согласовать с провайдером. Этот патч сам по себе их не решает.
- Без ручного курса USD загружается с официального XML ЦБ РФ, проверяется свежесть и кэшируется. При недоступной котировке/неподключённом провайдере покупка недоступна, случайная цена не придумывается.
- `FRONTEND_URL` должен указывать на ваш настоящий HTTPS-сайт (имя переменной проверьте в существующей конфигурации `.env.example`). Ключи — только на сервере, никогда в public/ или архиве для пользователей.
- Переход обратно с платёжной страницы не даёт подписку. Сервер самостоятельно проверяет сумму, валюту, статус и привязку к заказу у провайдера. Повторная проверка не начисляет месяц второй раз.
- Проверка проводится опросом; последние незавершённые заказы повторно проверяются при загрузке состояния продуктов. Вебхуки, автоматические возвраты, автопродление и полноценная бухгалтерия в эту предварительную версию не входят.
- До включения денег обеспечьте постоянный диск для SQLite, резервные копии и постоянные секреты авторизации. Эфемерная база на Render непригодна для хранения покупок.

## Установка

1. Сделайте резервную копию исходников и SQLite. Распакуйте патч с заменой файлов в корень репозитория. Базу не удалять: миграции добавляют поля и таблицы без сброса аккаунтов.
2. Разверните сервер и public/ вместе. По умолчанию оплата остаётся выключенной. Для проверки можно выдать Smart PC разработчиком на короткий срок без оплаты.
3. Соберите новое Windows-приложение через существующий ручной GitHub Actions **Build Windows installer (manual)**. Оно собирает неподписанный MSI 0.27.0. Старый MSI 0.20.0 не получает новые нативные методы от одного лишь обновления сайта.
4. Нативная проверка разрешений использует фиксированный HTTPS-хост `pongy-server.onrender.com`. Если API размещён на другом домене, измените build-time `PONGY_SMART_API_HOST` в native/windows/smart-pc-actions.h и пересоберите. Это нельзя подставлять произвольным URL из страницы.
5. Установите приложение, войдите в аккаунт с доступом, откройте «Умный ПК», разрешите микрофон. Проверьте остановку, истечение срока, команды и оплату сначала в тестовом окружении провайдера.

## Безопасность и ограничения

Каждой реальной команде нужен одноразовый серверный допуск на 15 секунд. Хранится хеш допуска; он связан с аккаунтом и версией сессии, недействителен после истечения подписки, отзыва или сброса сессии. Нативная часть принимает только заранее разрешённые действия после пользовательского согласия. Платёжное окно не получает нативный мост управления.

Нет выполнения произвольного кода, PowerShell, произвольных путей, чтения файлов, скриншотов, движения мыши, управления любыми элементами чужих окон. Поиск контакта «Мама» и отправка сообщений MAX **не реализованы**: помощник честно просит уточнение/сообщает ограничение. Зов не является биометрической авторизацией. Нужны интернет, работающий микрофон, WebView2 и проверка на настоящем Windows-компьютере. Работа при закрытой панели не заявляется: слушает открытая панель, а не независимая системная служба.

Платёжная страница открывается в отдельном окне приложения; отдельные банковские всплывающие окна могут открываться во внешнем браузере. Это не универсальный встроенный банковский клиент.

## Версии

Исходники — 0.27.0. Публичные MSI/APK остаются 0.20.0, пока вы отдельно не соберёте и не опубликуете новые пакеты. Архив патча не подменяет их и не переименовывает старые бинарники. Android и Linux не получают управление Windows.
