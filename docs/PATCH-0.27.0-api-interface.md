# API и оформление настроек — 0.27.0

Накопительный исходный патч поверх **smart-pc-preview 0.27.0**: включает исправление запуска/startup-network и текущие изменения API/интерфейса. Его также можно наложить после startup-network. Не является установщиком Windows или APK.

## Что изменено

- API-ключ для автозаполнения сохраняется при вводе, не только после выхода из поля. Очистка поля тоже запоминается. Провайдер, выбранная модель, загруженный каталог и согласие сохраняются для текущего аккаунта.
- Черновик настроек отличается от проверенного подключения. Фоновая проверка сервера больше не заменяет редактируемый черновик; для применения изменений нужна кнопка «Проверить и подключить». Непроверенные черновики не используются для автоматического восстановления подключения.
- Поздние ответы загрузки моделей не подменяют список после смены провайдера, изменения ключа или выхода из аккаунта. Поздние ответы сохранения не записывают данные в другой аккаунт.
- При смене провайдера ключ предыдущего сервиса не переносится в новый сервис; его потребуется ввести для выбранного провайдера. Это не удаляет уже действующий серверный ключ. Отключение серверного подключения — отдельная кнопка «Отключить ключ».
- Сервер сохраняет до 1000 загруженных моделей, вместо прежнего обрезания списка до 100. Увеличен допустимый размер зашифрованного зеркала; привязка к пользователю и проверка AES-GCM сохранены.
- Чтение нерасшифровываемой записи больше не удаляет её молча. Интерфейс сообщает о проблеме серверного секрета. Для корректной работы после развёртывания необходимы постоянная база и стабильный `JWT_SECRET`; патч не восстанавливает неизвестный старый секрет.
- «Выдача продукта» открывается через `showModal()` в верхнем слое браузера, отдельно от контейнера настроек. Явное центрирование и ограничения высоты/ширины рассчитаны на большой и узкий экран. Добавлены кнопка закрытия, доступное название, фокус на почте получателя и возврат фокуса после закрытия.
- Диалоги используют действительные переменные светлой/тёмной темы. Подровнены поля, кнопки, интервалы и действия выдачи/отмены. Переходы цветов, рамок, фокуса и фона согласованы; режим уменьшенных анимаций сохраняется.

## Какие данные не должны появляться в пустом поле

Если подключение существует на сервере, но локальной копии ключа в этом браузере нет, поле секрета остаётся пустым с подсказкой «Ключ сохранён на сервере». Это намеренная защита: GET API не возвращает сохранённый секрет. Провайдер, модель, каталог и согласие при этом отображаются. Для проверки нового подключения или изменения модели на таком устройстве ключ потребуется ввести заново.

Копия автозаполнения в браузере обфусцирована и привязана к аккаунту, **но это не криптографическая защита от кода, работающего в том же origin**. Серверная запись зашифрована AES-256-GCM; запросы развёрнутого сайта должны идти по HTTPS. Не включайте ключи в URL, журналы или публичные архивы.

## Применение

1. Сделайте резервную копию проекта, постоянной базы и конфигурации окружения.
2. Распакуйте исходный ZIP в корень текущего проекта с заменой файлов. Не удаляйте базу, cookies, локальные данные или секреты. Архив содержит только изменённые/добавленные исходники; это не полный проект с зависимостями.
3. Разверните **сайт и Node-сервер**. Перезагрузите страницу обычным способом. Изменения API требуют обновления сервера, одних CSS/JS недостаточно.
4. Текущие улучшения настроек отображаются и в приложении, которое загружает обновлённый сайт. Нативные исправления белого экрана из включённого startup-network требуют отдельной пересборки/обновления оболочки; см. [инструкцию запуска](PATCH-0.27.0-startup-network.md).
5. Старый запуск GitHub `40902455770` относится к прежним исходникам. В архив включены исправления `weather missing` и извлечения JavaScript в тесте языка установщика. После применения нужно запустить новый workflow, старый журнал не изменится.

## Ограничения

- Недоступность `onrender.com/healthz` без VPN не исправляется оформлением или сохранением API. Необходим доступный пользователям маршрут/домен сервера; VPN-доступность не означает ошибку сборки.
- Опубликованные MSI/APK 0.20.0 не подменяются и не переименовываются. В этом патче новых установщиков нет.
- Платежи, доступность внешних AI-провайдеров и доставка почты требуют рабочей конфигурации; тесты не подтверждают их работу на вашем продакшене.
