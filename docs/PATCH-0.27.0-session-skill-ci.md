# Pongy AI 0.27.0 — повторный вход и проверка анимаций

## Установка

Распакуйте архив поверх **motion-ci-hotfix 0.27.0**, сохраняя структуру каталогов. Затем запустите GitHub Actions заново. Это небольшой патч тестов и документации: сервер, сайт, база данных, зависимости и установщики не изменены. Удалять данные, отключать защиту или заново разворачивать сайт для этого патча не требуется.

## Причины

- В длинном сценарии session-ui после нескольких перезагрузок и восстановления истории срабатывает настоящий серверный лимит 200 запросов/минуту. Предварительная проверка /api/me со статусом 200 не резервирует бюджет: повторный /api/login ещё может вернуть 429. Раньше тест ждал готовности чата, хотя вход был отклонён.
- В skill-menu-ui режим движения менялся прямой записью в атрибут корневого элемента. Асинхронно применяемые настройки могли перезаписать его. Это та же ошибка организации теста, которая ранее исправлялась для Motion.

## Исправления

- Каждый вход через форму проверяет настоящий ответ POST /api/login. Только при 429 допускается один повтор после указанного сервером Retry-After (не более 60 секунд + 1 секунда запаса). Повторный 429, некорректный заголовок, 401/403 и другие ошибки не скрываются. Серверные лимитеры, cookie и проверки авторизации остаются включены.
- Выбор полной и уменьшенной анимации проходит через настройки интерфейса. Проверки ждут согласованного режима и вычисленных CSS-свойств, а не произвольной задержки. Все 25 проверок навыков сохранены.
- Диагностика session-ui дополнена текстом ошибки входа и состоянием нижней строки. Секреты в неё не добавлены.

Версия остаётся 0.27.0: это исправление CI, а не новая сборка приложений. Проверки и ограничения перечислены в [отчёте](VALIDATION-0.27.0-session-skill-ci.md).
