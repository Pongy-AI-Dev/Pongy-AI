# 0.27.0 — UI/mail hotfix

Небольшой дополнительный патч поверх **0.27.0 plugins-skills**. Распаковать в корень репозитория с заменой файлов, затем выполнить деплой Render. Новых npm-зависимостей и изменений базы нет. Нативные пакеты и расширение не пересобираются, версия исходников остаётся 0.27.0.

## Изменения
- Центровка плюса, поля ввода и соседних кнопок; сохранён многострочный ввод.
- «Подключения» и SVG цепочки вместо неясной иконки.
- Создание навыка — правая панель: редактируемые название и описание сверху, ниже чат с ИИ; сохраняются значения полей, сохранение явное. На мобильном панель адаптируется к ширине экрана.
- Убрана подпись о мужских/женских голосах устройства. Карточка расширения короче, реальные ограничения Chrome/Edge сохранены.
- Состояния прослушивания, почтового теста и проверки разработчика анимированы; плавное раскрытие дополнительных поверхностей, reduced motion соблюдается.
- Инструкция ИИ избегать пустых скобок и лишнего рассказа о провайдерах. Значимые скобки, формулы, код, ссылки и обязательная атрибуция не вырезаются. Это не гарантия безошибочности модели.

## Почта: что исправляет код и что необходимо настроить
Одиночный оставшийся SMTP_PORT больше не перехватывает выбор Resend в режиме auto. Полная SMTP-конфигурация по-прежнему приоритетна; можно явно выбрать MAIL_PROVIDER=resend или smtp. Ошибки авторизации, ограничений отправителя, лимита и подключения теперь различаются без раскрытия ключей или сырых ответов. TLS-проверки не отключаются. Отказ провайдера не считается успешной доставкой.

Для Render при проблемах доступа к SMTP можно использовать уже поддерживаемый Resend по HTTPS:

```
MAIL_PROVIDER=resend
RESEND_API_KEY=<ваш ключ в Render, не в репозитории>
MAIL_FROM=Pongy AI <notifications@ваш-подтверждённый-домен>
```

Подтвердите отправляющий домен в Resend и необходимые DNS-записи. Не ставьте адрес Gmail в MAIL_FROM для произвольного Resend-домена. Тестовый отправитель провайдера может иметь ограничения получателей. Сохраните Environment, дождитесь деплоя и нажмите проверку почты. Ответ «принято сервисом» означает приём отправки, а не гарантированное попадание во входящие.

Для SMTP: MAIL_PROVIDER=smtp, SMTP_HOST, SMTP_PORT, SMTP_SECURE, SMTP_USER, SMTP_PASS, MAIL_FROM; SMTP_PASS для Gmail — пароль приложения, не обычный пароль. Доступность портов зависит от тарифа/сети Render. Сам патч не выдаёт ключи, не подтверждает домен и не меняет настройки вашего аккаунта Render. Напоминания и браузерные уведомления не требуют успешной доставки почты.
