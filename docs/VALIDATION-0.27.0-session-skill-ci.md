# Проверки session / skill CI 0.27.0

## Причина подтверждена

Исходный сбой воспроизведён с реальными HTTP-статусами: /api/logout — 200, следующий /api/login — 429. Форма входа правильно показывает серверную ошибку, но старый тест не проверял ответ входа и ждал историю 30 секунд. Успешный предварительный /api/me не гарантирует бюджет для последующих запросов.

В старом тесте навыков обнаружена прямая запись data-motion, конфликтующая с асинхронным применением настоящих настроек. Для полной и уменьшенной анимации теперь используется переключатель настроек, ожидание согласованного состояния и вычисленных CSS-свойств. Проверки анимаций не удалены.

## Выполнено после исправления

- Полный `npm test`: **725/725**, ошибок, отмен и пропусков нет.
- Полный `CI=1 BROWSER_ENGINE=chromium npm run test:ui`: **57/57 наборов**, включая session-ui (39 проверок) и skill-menu-ui (25 проверок).
- Отдельные session-ui и skill-menu-ui прошли в Chromium и Firefox: 39 и 25 проверок соответственно на каждом движке.
- Пять новых модульных тестов проверяют обработку настоящего 429 с Retry-After, отсутствие повторов для 401/403/5xx, ограничение числа повторов, отказ при некорректной/слишком большой задержке и распространение сетевых ошибок.
- Серверные лимитеры не отключены; авторизация не подменена успешным ответом. Ожидание повтора допускается только для 429. Изменений рабочих JS/CSS сайта и сервера в архиве нет.

## Ограничения

WebKit локально не запускался из-за несовместимых системных библиотек среды. Его результат должен быть подтверждён следующим запуском GitHub Actions. Полный Firefox UI-прогон не выполнялся: проверены два затронутых набора. Успешные локальные проверки не гарантируют отсутствие всех ошибок на всех устройствах.

Архив предназначен для наложения поверх motion-ci-hotfix 0.27.0. Версия исходников остаётся прежней; установщики не пересобирались. Новых пользовательских функций не добавлено, поэтому публичные заметки об обновлении сайта не менялись.
