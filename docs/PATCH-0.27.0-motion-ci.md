# Pongy AI 0.27.0 — исправления Motion и сохранения настроек

## Установка

Наложите содержимое архива на проект **после патча Motion и единого стиля 0.27.0**, сохраняя структуру каталогов. Обновите сервер и файлы сайта, затем перезагрузите страницу. Не удаляйте базу данных, настройки, пользовательские файлы или переменные окружения. Зависимости не изменились.

- Экспорт Motion проверяет поддержку WebM. После подготовки видео нажмите «Скачать готовое видео». Если экспорт недоступен, плеер сообщает об этом; предпросмотр остаётся доступен.
- Уже скачанные ZIP-проекты содержат старый плеер: создайте проект Motion заново, чтобы получить исправления.
- При уходе со страницы сохранение настроек отменяется безопасно; неподтверждённые изменения остаются в локальной очереди для повторной отправки.
- Пути снимков экрана переносимы; проверка анимаций использует настоящие настройки интерфейса.

Это дополнительный патч исходников 0.27.0, не новый выпуск MSI/APK. Установщики не пересобирались. WebM без звука; MP4 и серверный рендеринг не добавлены.
