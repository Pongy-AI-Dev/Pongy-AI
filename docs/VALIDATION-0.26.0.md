# Проверки 0.26.0

## Среда и границы

Linux, Node.js 24, локальный Chromium с `CHROMIUM_PATH`. Только контролируемые тестовые аккаунты и данные. Изменений в развёрнутом Render/пользовательском браузере не производилось. Firefox/WebKit и Edge отдельно локально не запускались. Нативные Windows/Android установщики не собирались.

Голосовые UI-тесты проверяют реальное приложение/HTTP-чат с управляемыми заглушками SpeechRecognition и speechSynthesis. Проверены сохранение одного исходного composer, черновики, отправка одной реплики, отсутствие распознавания во время озвучивания, следующий ход только после конца речи, пауза/закрытие/смена видимости, ошибка доступа микрофона и обычная ручная диктовка после выхода. Они не проверяют качество распознавания реальной речи и доступность голоса ОС.

Расширение проверено отдельно: настоящий MV3-компонент загружается Chromium в временном профиле; контролируемый HTTPS origin вызывает реальный внешний мост; default-off не переключает вкладку, opt-in активирует только исходную вкладку, отключение отзывает разрешение. Состояние active проверяется Chrome API, а не visibilityState headless-страниц. Это не проверка фокуса других окон ОС. Модульные тесты дополнительно проверяют запрет другого origin, навигацию вкладки, игнорирование подставного tabId, ограничения разрешений и отказ API.

Визуально просмотрены live-снимки 1280×900, 390×844 (светлая/тёмная темы) и 844×390. Снизу остаются инструменты и поле ввода; нет второго микрофонного индикатора, горизонтального переполнения и перекрытия обоих выходов. На малой высоте маскот уменьшается, информация о распознавании остаётся доступной. Отдельный статический HTML-снимок проверен capture_html: без горизонтального/вертикального переполнения и ошибок скриптов; скрытые старые логотипы/иконки из file://-снимка не включены в автономный предпросмотр. Рабочий интерфейс проверен через локальный HTTP-сервер.

## Итоговые результаты

- Полный unit/server-прогон на проекте, восстановленном наложением патча: **638/638 passed**, без пропусков.
- Финальный полный Chromium UI-прогон: **48/48 suites passed**, exit code 0. Включает прежние напоминания, Connections, настройки, историю и новые голосовой режим/настоящее расширение.
- Отдельный финальный voice-mode UI-прогон: **39 assertions passed**; настоящее расширение: **9 assertions passed**. После переноса запуска расширения в общий browser helper его реальная проверка повторена успешно.
- `npm run check:release` на исходном и восстановленном дереве: passed; 370 исходных файлов, 224 JS и 6 JSON, до добавления иных пользовательских файлов.
- При первом промежуточном UI-прогоне тест расширения ошибочно ожидал DOM visibilityState=hidden в headless Chromium (47/48). Исправлена именно проверка: теперь реальная активная вкладка проверяется Chrome API, production-защиты не отключались. Промежуточный unit-прогон нашёл, что тест расширения обходил общий launcher; добавлен общий persistent-context helper и сохранена проверка отсутствия прямых запусков браузера в suites. Повторный полный unit/финальный UI-прогоны успешны.
- Никакие предупреждения SMTP/Firebase/AI-тестовых отказов не выдаются за реальную настройку сервисов: тесты используют управляемые fixtures. Настройка почты в Render этим патчем не меняется.

## Целостность

Архив патча сравнивается с точным деревом 0.25.0 предыдущего connected-actions патча. Проверяется отсутствие удалений, безопасные repo-relative пути ZIP, восстановление всех исходников наложением, совпадение байт восстановленного проекта и SHA-256 manifest. Новых зависимостей, секретов, `.env`, баз данных, runtime-данных и собранных установщиков в архиве нет. Отдельный архив расширения содержит только README, manifest и локальные JS/HTML/CSS; manifest лежит в корне. Открытый публичный `key` в manifest задаёт стабильный ID и не является секретом.
