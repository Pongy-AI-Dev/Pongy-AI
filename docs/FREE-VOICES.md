# Обновление 0.27.0: Piper действительно подключён

Добавлена опциональная локальная интеграция Piper 1.3.0 / `ru_RU-denis-medium`, а не только исследование или список названий. Установка/выбор: [PATCH-0.27.0](PATCH-0.27.0-plugins-skills.md#настоящий-локальный-нейроголос-piper). Без установки и выбора пользователя сохраняется прежний браузерный движок. Английский Kokoro по-прежнему не подключён.

Runtime: [OHF-Voice/piper1-gpl](https://github.com/OHF-Voice/piper1-gpl), **GPL-3.0-or-later** (проверено по установленному пакету `piper-tts==1.3.0`). Модель: [Denis MODEL_CARD](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/denis/medium/MODEL_CARD). В карточке датасет CC0; это не основание объявлять любой голос Piper или runtime MIT. Самостоятельный хостинг требует вычислительных ресурсов.

# Бесплатные голоса: что реально доступно Pongy

Это подборка кандидатов, а не заявление об объективно «лучшем» голосе: звучание нужно прослушать на устройстве. В патче добавлены **Настройки → Интерфейс → Конкретный голос → Прослушать**. Список содержит только реальные голоса, предоставленные `speechSynthesis`, а выбор сохраняется отдельно для русского и английского на этом устройстве. Автовыбор остаётся доступен. Никаких фиктивных «ChatGPT voice» или незаявленных платных запросов нет.

## Без отдельного сервера

1. **Системные улучшенные голоса Apple.** В macOS: System Settings → Accessibility → Read & Speak → System voice → Info; можно загрузить дополнительные голоса и прослушать образец. Голос доступен после окончания загрузки. После установки перезагрузите Pongy и проверьте его в списке. Браузер может предоставлять не все системные голоса. [Apple](https://support.apple.com/guide/mac-help/change-the-voice-your-mac-uses-to-speak-text-mchlp2290/mac).
2. **Google / Microsoft / Natural / Neural в списке браузера.** Если они реально доступны через Web Speech, их можно выбрать и прослушать в Pongy. Наличие зависит от ОС, браузера и языка. Голос с пометкой «онлайн» может отправлять текст сервису синтеза, даже без отдельного API-ключа Pongy.
3. **Microsoft Edge Read aloud.** У самого Edge есть естественные голоса и выбор скорости; онлайн-режим предоставляет больше вариантов, чем офлайн. Но это функция браузерного чтения страницы: её голоса нельзя обещать как публичный бесплатный TTS API для сайта. Если нужный голос не появился в `speechSynthesis.getVoices()`, Pongy не может назначить его лишь по названию. Непубличный endpoint Edge этим патчем не используется. [Microsoft](https://www.microsoft.com/en-us/edge/features/read-aloud?ch=1).

## Бесплатные модели для отдельного локального/собственного TTS

- **Русский: Piper `ru_RU-denis-medium`.** Карточка модели указывает русский язык, одного диктора, 22 050 Гц и **CC0 для набора данных**. Это кандидат для собственного офлайн-движка, не готовый системный голос, который можно добавить одной строкой JavaScript. Лицензии выбранного runtime и самих весов нужно проверить отдельно; бесплатность модели не означает бесплатный сервер. [Оригинальная карточка](https://huggingface.co/rhasspy/piper-voices/resolve/main/ru/ru_RU/denis/medium/MODEL_CARD).
- **Английский и поддерживаемые языки: Kokoro-82M.** Открытые веса под Apache-2.0, пригодные для собственного размещения. Перед выбором проверяйте список поддерживаемых языков: наличие мультиязычности не означает поддержку русского. Официальный пример использует `af_heart`. Это не облачный бесплатный безлимитный endpoint. [Официальная карточка](https://huggingface.co/hexgrad/Kokoro-82M).

Piper/Kokoro **не установлены и не загружены скрытно**. Их подключение потребует согласованного runtime, весов, ресурсов устройства/сервера и проверки лицензий; это отдельная работа, а не гарантированный бесплатный режим на маленьком Render instance. В текущем патче реальное улучшение — выбор/прослушивание доступных голосов, а не обещание, что старый системный синтез стал новой нейросетью. Для одинакового качественного русского звучания на всех платформах потребуется отдельный согласованный движок.
