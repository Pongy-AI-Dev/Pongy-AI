# Проверка патча 0.23.1

## Выполнено в Linux / Node 24 / Chromium

- `npm test`: **572/572** теста, без пропусков. Отдельно повторены пять новых тестов после окончательной корректировки голосового пути.
- 14 релевантных браузерных сценариев: **380 проверок**. Пройдены новые настройки/роль разработчика, интерфейс 0.23.0, API/MCP/разработчик, голосовой триггер, настоящее офлайн-распознавание, дисплей/сохранение настроек, reduced motion, контакты/голос/undo, вложения, мобильные напоминания, нативный файловый мост (браузерный тест), заметки, версия/время и предупреждения сервиса.
- Голосовые проверки окончательного варианта: 15 проверок триггера и 18 проверок настоящего Vosk/восстановления. Браузерный движок в сценарии триггера искусственно возвращает сетевую ошибку, затем офлайн-резерв сохраняет автоматическую отправку команды и завершение по тишине.
- Проверены «Понги», «Он ге», «О ге», «Ольге», команды после обращения, отсутствие активации от упоминания имени внутри предложения и от неоднозначного промежуточного слова. Это проверки обработки транскрипта, а не замена испытаний с микрофоном пользователя.
- Настоящая русская WAV-запись распознана настоящей моделью Vosk. Для детектора проверены **все завершённые сегменты**, а не только их объединение. Узкая грамматика была отклонена: на обычной речи получала ложное «о ге». Окончательный вариант использует полный словарь и не активируется на данной контрольной записи.
- HTTP-проверки двумя аккаунтами: отключение сайта и обслуживание блокируют обычного пользователя, оставляют доступ подтверждённому разработчику; чёрный список ограничивает уже открытый сеанс и новый вход; удаление из списка восстанавливает доступ. Проверены нормализация адреса, запрет блокировки разработчика и сохранение в SQLite после повторного открытия базы.
- Визуально осмотрены снимки 1440×1000 и 390×844: главная страница, Plus, настройки интерфейса сверху/снизу, русская и английская локализации, тёмный режим. Отдельно выполнен HTML capture helper. Проверены отступы, размеры иконок, выбранный цвет и отсутствие горизонтального переполнения.
- `npm run check`: структура, синтаксис JavaScript/JSON, локальные зависимости, отсутствие обнаруженных шаблонов секретов.
- Архив проверяется наложением на восстановленную 0.23.0, побайтовым сравнением файлов и `npm run check:release` с полным `MANIFEST.sha256`.

## Ограничения проверки

Это не гарантия отсутствия всех ошибок. Полный набор из 40 браузерных сценариев на всех трёх движках не запускался: выбранные 14 проверены в Chromium. Живая речь пользователя, её акустика, доставка на настоящие почтовые ящики, продуктивный сервер и многоэкземплярное развёртывание не проверялись. Нативные MSI/APK не собирались и не подписывались; проверка браузерного моста не является запуском настоящего установщика в Windows. Узкая грамматика не поставляется. Качество Алисы и универсальное управление Windows не заявляются.
