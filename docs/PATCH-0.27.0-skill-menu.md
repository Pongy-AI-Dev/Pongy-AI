# Pongy AI 0.27.0 — блоки и меню навыков

Небольшой дополнительный патч **поверх 0.27.0 comfort-skills hotfix**. Замените файлы из архива в корне проекта и выполните деплой. Зависимости, база данных и почтовые настройки не меняются. Нативные приложения в этом патче не пересобираются.

Выбранный навык теперь имеет тот же прямоугольный стиль, размеры и выравнивание, что и режим программирования/изображений. Вместо крестика используется центрированная кнопка минус.

Стрелка быстрого списка — отдельная настоящая кнопка, а не вложенный интерактивный элемент. Список появляется немедленно из сохранённого состояния или со статусом загрузки, не ожидая сетевого запроса. Данные обновляются в фоне. Есть анимации появления/закрытия, задержка закрытия для перехода курсора в список, управление с клавиатуры, ограничение по краям экрана и поддержка уменьшенного движения. Сохраняется выбор только одного навыка.

Регрессионный тест `tests/skill-menu-ui.cjs` включён в штатный UI runner и проверяет реальное наведение, медленную сеть, анимации, выравнивание, клавиатуру, мобильную ширину и кнопки минус.
