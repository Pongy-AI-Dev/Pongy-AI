# Pongy AI 0.26.1 — CI hotfix теста расширения

## Установка

Наложить ZIP на корень полного проекта **0.26.1 focus-download**, сохранив пути и заменив одноимённые файлы. Старые документы, `.env`, БД и прочие файлы не удалять. Закоммитить изменения и повторно запустить GitHub Actions. Изменений приложения/сервера, npm-зависимостей, OAuth, Render, микрофона и ZIP расширения нет. Установщики не пересобраны. Версия остаётся 0.26.1, поскольку исправлен только тестовый запуск и документация к нему.

## Причина

`focus-extension-ui.cjs` запускался с headless:true без channel. Стандартный Playwright в GitHub Actions выбирает отдельный headless-shell, в котором MV3-расширение не загружалось. В результате ожидание события serviceworker истекало через 30 секунд. Предыдущая локальная проверка использовала явный CHROMIUM_PATH к полному Chromium и не выявила это различие. Та же ошибка воспроизведена на bundled Chromium Playwright с CI=true, без локальной подмены executablePath.

Официальная документация Playwright рекомендует `channel: 'chromium'` для расширений в headless: https://playwright.dev/docs/chrome-extensions . Persistent context уже использовался и сохраняется.

## Изменение

Только `launchExtensionContext` получает собственную проверяемую конфигурацию `getExtensionBrowserConfig`: channel='chromium', headless=true, serviceWorkers='allow'. В CI применяется bundled Chromium, локальная подмена пути в CI по-прежнему игнорируется. Для Firefox/WebKit helper по-прежнему выдаёт явную ошибку; их suite расширения честно пропускает как неподдерживаемые движки. Обычный `launchBrowser` не меняется, Service Workers в его сетевых fixtures остаются заблокированы.

Существующий шаг `playwright install --with-deps chromium` уже устанавливает полный Chromium — изменять workflow, добавлять Xvfb, увеличивать тайм-аут, отключать проверки или разрешения безопасности не нужно. Иконка и код распространяемого расширения не менялись; пользователям не нужно переустанавливать расширение.

## Проверки

- До исправления: CI=true BROWSER_ENGINE=chromium, без CHROMIUM_PATH — тот же Timeout 30000ms while waiting for serviceworker.
- После: тот же bundled Chromium, channel='chromium' — 9 реальных проверок расширения проходят. Фоновый MV3 Worker действительно загружается, внешний мост переключает вкладку, default-off и отключение разрешения проверяются.
- Добавлены unit-проверки CI-конфигурации, неизменности обычного запуска/блокировки Service Workers и отказа другим движкам.
- Повторный прогон с CI=true и без CHROMIUM_PATH: 3 запуска настоящего расширения подряд (по 9 проверок), затем скачивание ZIP (16), голосовой режим (39) и навигация настроек (45): **6/6 запусков прошли**, 4 уникальных UI-набора. Это не новый полный 49/49 прогон.
- Полный unit/server-прогон: **644/644 passed**, без пропусков. Отдельная группа browser/extension/docs: **18/18 passed**.
- В восстановленном наложением архиве повторены source/release audit, 18 целевых unit-тестов и настоящий тест расширения в режиме CI (9 проверок): passed. Проверены совпадение всех 376 исходных файлов и SHA-256 manifest. В архиве только изменённые/новые файлы.

Headless-тест подтверждает активацию вкладки Chrome API, а не фокус других программ ОС или качество распознавания реального микрофона. Полный запуск GitHub-hosted Ubuntu runner из этой среды не выполнялся. Предыдущий присланный пользователем прогон имел 48/49 UI-наборов; это не объявляется новым полным успешным прогоном.
