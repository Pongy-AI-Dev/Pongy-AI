# Проверка патча 0.23.0

Окружение: Linux, Node.js 24, локальный Chromium; основа — предоставленный архив с версией package.json 0.22.2 (ZIP comment: ffcaf7a3ac0fd2f8936bed3543432765b592fe12).

## Выполнено

- До изменений: **561/561** серверных/модульных тестов прошли.
- После изменений: **567/567** тестов, включая шесть новых регрессионных проверок: поля напоминаний, разговорные даты, Unicode-названия, ограничения Windows-действий, реальная серверная связка SMTP-адаптера, смешанный ZIP. Почтовые проверки включают локальный TLS SMTP и имитацию провайдера, **не реальный Gmail**.
- `npm run check`: структура, JavaScript/JSON-синтаксис, локальные зависимости и сканирование известных форм секретов.
- `npm audit --omit=dev`: **0 известных уязвимостей** на момент проверки после Nodemailer 10.2.1. Это не полный аудит безопасности.
- **12 выбранных браузерных наборов Chromium**: все прошли, суммарно 313 утверждений. Это не весь многобраузерный CI.

Голосовой набор использует имитированный микрофон и распознаватель для детерминированной проверки состояний. Отдельный speech-ui прогоняет реальный локальный Vosk на записанном русском аудиофрагменте. Это не испытание живого микрофона или системной фоновой активации.

Визуально просмотрены снимки мобильных цветов, центрированного списка изменений и формы напоминания. Дополнительный захват HTML 390×844 не обнаружил горизонтального/вертикального переполнения viewport, ошибок скриптов и ресурсов. Длинные окна имеют внутреннюю прокрутку. Промежуточная ошибка центрирования исправлена; мобильный тест обновлён под новое требование явно указать недостающие дату/время.

## Не проверено / не выполнено

- Подключение к вашему SMTP/Resend и доставка на реальные почтовые адреса.
- Внешний ИИ-провайдер с вашими ключами и качество ответов на произвольные запросы.
- Живой микрофон, голоса и фоновые ограничения на вашем компьютере/телефоне.
- Компиляция и установка изменённых Windows/Android-приложений; нативный Windows-мост проверен чтением исходника и тестами ограничений предложений, **не компилятором и не реальной Windows**.
- Выпуск подписанного APK/MSI 0.23.0, полный контроль Windows, гарантированный вывод обычной браузерной вкладки поверх других окон.
- Firefox/WebKit и остальные невыбранные браузерные наборы.

До публикации выполните полный CI и проверки реального окружения из `docs/PATCH-0.23.0.md`. Ни один набор тестов не доказывает отсутствие всех ошибок.
