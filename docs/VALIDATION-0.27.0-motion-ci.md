# Проверка исправлений Motion / CI 0.27.0

## Выполнено

- `npm test`: 720/720 тестов, без пропусков и ошибок.
- Chromium и Firefox, режим CI: motion-style-ui (15), motion-video-ui (14), auth-polish-ui (22), preferences-persistence-ui (25) — все прошли на обоих движках.
- Регрессии Firefox: session-ui (39), auth-polish-ui (22), settings-navigation-ui (45), motion-ui (29), reliability-ui (11) — все прошли.
- Те же регрессии Chromium прошли, кроме первоначального session-ui: лимитер вернул 429 перед выходом. Проверка теперь дожидается разрешённого сервером Retry-After, не отключая лимитер. Повтор session-ui: 39 проверок прошли.
- Экспорт проверен настоящими файлами WebM (включая сигнатуру), а не только появлением кнопки.
- Отдельные проверки исполняют реальный код встроенного плеера: отсутствие WebM, ошибка запуска, успешное завершение, отмена в фоне, ограничение зависшего рекордера.
- Проверяется отмена сохранения настроек при уходе со страницы, сохранение очереди и защита от запоздавшего подтверждения старой версии.

## Ограничения

WebKit здесь не запущен: доступный бинарный пакет требует более новой glibc, чем установлена в среде. Результат WebKit нужно подтвердить в GitHub Actions. Причина ошибки access control в WebKit не воспроизведена локально: исправлена обнаруженная гонка сохранения при закрытии/смене страницы, но это не заявление о проверенной совместимости WebKit.

Полный UI-прогон всех 57 наборов заново не выполнялся. Новые проверки не подменяют неподдерживаемый экспорт успешной загрузкой и не ослабляют аутентификацию/CORS. Предупреждение об отсутствии настроенной почты не является причиной описанных падений CI; этот патч не настраивает SMTP/Resend.
