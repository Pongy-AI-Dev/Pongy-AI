# Pongy AI 0.26.1 — документация и расширение в активации голосом

## Применение

Дополнительный патч поверх полного проекта **0.26.0 voice-mode**. Распакуйте с repo-relative путями и заменой одноимённых файлов, не удаляя остальные документы, `.env`, БД и загрузки. Опубликуйте обновлённый фронтенд (включая каталог `public/extensions`) и сервер Render, затем перезагрузите сайт. Новых зависимостей npm, секретов, миграций и OAuth-настроек нет. Версии исходников Windows/Android согласованы, опубликованные MSI/APK 0.20.0 не пересобраны.

## Скачивание внутри сайта

Откройте **Настройки → Интерфейс → Активация голосом**. Ниже переключателя — блок «Переключение вкладки по зову», кнопка скачивания расширения Chrome/Edge и раскрывающаяся инструкция. Блок доступен и при выключенной активации: разрешение микрофона не требуется для скачивания ZIP. В английском интерфейсе подписи и инструкция переводятся.

ZIP содержит готовую папку расширения: распакуйте её в постоянное место, откройте `chrome://extensions` / `edge://extensions`, включите режим разработчика → «Загрузить распакованное». Выберите папку с manifest.json. В окне расширения включите «Разрешить переключение вкладки», перезагрузите Pongy и включите голосовую активацию/разрешите микрофон. Автоматическая установка браузером не выполняется. ID и разрешения расширения прежние; если уже установлена версия 0.26.0, её связь с сайтом сохраняется.

ZIP `/extensions/Pongy-Wake-Focus-0.26.1.zip` поставляется с фронтендом и загружается с его origin, без приватного API или входа. Нужны именно файлы из `public` на публичном frontend-хостинге, а не только деплой API на Render. Не переносите ZIP в пользовательский DATA_DIR.

Расширение не слушает микрофон само. Зов должен быть распознан открытой, не замороженной/выгруженной вкладкой Pongy. Ограничения фона, ОС и микрофона не обходятся. Настольные Chrome/Edge; это не расширение для Firefox/Safari/мобильных браузеров. Фокус окна может быть ограничен ОС. Подробные границы голосового режима сохранены в PATCH-0.26.0-voice-mode.md.

## Документация

README и RELEASES показывают актуальную 0.26.1; CHANGELOG содержит недостающие версии 0.23.1–0.26.0 и текущую запись. Исторические тексты и отдельные PATCH/VALIDATION-документы сохраняют версии своих выпусков. `public/downloads/releases.json` обновляет верхнюю версию исходников, но не меняет версии, имена, хэши и содержимое опубликованных MSI/APK 0.20.0.

Добавлены автоматические проверки согласованности текущей документации, истории, release-notes, версии и содержимого скачиваемого ZIP; UI проверяет скачивание непосредственно из настроек, локализацию и размеры экрана. Итоговые результаты: VALIDATION-0.26.1.md.
