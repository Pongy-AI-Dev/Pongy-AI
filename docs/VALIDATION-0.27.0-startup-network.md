# Проверки исправления загрузки 0.27.0

- `npm test`: **742 теста пройдены**, 0 ошибок. После последнего уточнения обработки SSL Android повторно пройдены 14 целевых тестов запуска/автономной оболочки/UI-runner.
- Полный Chromium UI-runner: **59/59 наборов пройдены**. Включает обе ранее падавшие проверки: extensions-ui (38 утверждений) и installer-language-ui (10), а также новый startup-ui (8).
- Новый startup-ui реально блокирует загрузку app.js в Playwright: проверяет понятный экран повтора, успешную повторную загрузку, сохранность localStorage, таймаут медленного скрипта и исчезновение предупреждения при позднем успешном старте.
- Отдельно пройдены тесты таймаута Service Worker, остановки зависшего fetch и публичного fallback при HTTP 503. API, авторизация и скачивания не заменяются offline-HTML; личные ответы не кэшируются.
- Windows EXE скомпилирован и слинкован MinGW C++17 с официальным WebView2 SDK 1.0.3537.50. Android MainActivity скомпилирован javac --release 8 с официальным android-35 android.jar.
- Патч проверяется наложением на 443 файла исходной smart-pc-preview версии и сверкой SHA-256 всех результирующих исходников. `check:release` проверяет структуру, синтаксис и манифест.

## Не проверено / не обещается

Настоящий запуск Windows/Android на устройстве, текущий установленный пользователем WebView, сеть пользователя без VPN и повторная матрица Firefox/WebKit здесь не проверялись. Chromium проходит локально; остальные движки остаются в GitHub Actions и не отключены. Компиляция Android не равна сборке подписанного APK, а компиляция Windows не равна аппаратной проверке приложения. Старые опубликованные MSI/APK не заменены.

`JSON.parse` в старом installer-language-ui падал из-за слишком широкого регулярного выражения в тесте, а не из-за доказанной синтаксической ошибки нативного JavaScript. Исправление этой проверки не выдаётся за доказанное устранение белого экрана на устройстве пользователя.

Прямые HTTP-проверки домена и API из среды разработки дали 200; это не доказательство доступности из конкретной страны, провайдера или мобильной сети. Обход DNS/CDN/сетевых ограничений патч не заявляет. Реальные платежи, SMTP и управление сторонними приложениями этот хотфикс не меняет.
