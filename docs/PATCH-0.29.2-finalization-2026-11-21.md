## Безопасное обслуживание файлов

- Добавлен анализ ссылок на файлы в чатах, проектах, заметках и Library.
- Старые неиспользуемые файлы (90+ дней) предлагаются в список проверки, но не удаляются автоматически.
- Перемещение в корзину требует подтверждения; восстановление возможно 30 дней.
- После перемещения в корзину файл блокируется для скачивания, предпросмотра и повторного прикрепления до восстановления.
- Безвозвратное удаление разрешено только после 30 дней в корзине и отдельного запроса.
- API: 1/1 end-to-end тест; Library UI: 17/17 assertions in Chromium, Firefox and WebKit.

## Неподтверждённые внешние и отложенные проверки

- Реализован ограниченный opt-in оркестратор Planner → Reviewer → Worker. Планировщик формирует bounded-план, независимый Reviewer проверяет завершённый черновик, Worker может исправить замечания, после чего результат проходит повторную проверку до упаковки артефакта. При недоступности независимой модели система явно сообщает о fallback и не выдаёт непроверенный текст за прошедший review. Unit/UI-тесты проверяют handoff, отказ Reviewer, repair/re-review, ограничения контекста и обычный маршрут. Реальные live-запросы ко всем ролям требуют активных ключей и квот и в локальной среде не подтверждались.
- Живые запросы ко всем внешним API требуют действующих пользовательских ключей, квот и региональных разрешений; в локальной среде эти учётные данные отсутствовали.
- Полная Android-прошивочная матрица требует реальных устройств/эмуляторов; текущая проверка подтверждает API 23–35 и защитные проверки совместимости, но не каждую OEM-прошивку.
- Для Windows MSI необходима отдельная проверка установки/обновления в чистой Windows VM и Authenticode-подпись выпуска.
