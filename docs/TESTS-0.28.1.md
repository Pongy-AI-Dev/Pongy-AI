# Проверки 0.28.1

- Полный `npm test`: **775/775**, 0 ошибок, 0 пропусков.
- Дополнительный сфокусированный прогон Motion/плагинов/Matroska: **29/29**.
- Реальный Chromium Motion UI: **19 проверок**, включая настоящие скачивания WebM, поддерживаемого MP4 и MKV, отсутствие внешних запросов и мобильную ширину.

- Источники OAuth-инструкции: текущие callback/scope/config проекта и официальная документация Google, указанная в самой инструкции. Настройки Google Cloud пользователя не просматривались и не изменялись.
- Синтаксис, MANIFEST и наложение поставляемого ZIP на исходную базу проверяются отдельно. Это не гарантия отсутствия всех возможных ошибок.
