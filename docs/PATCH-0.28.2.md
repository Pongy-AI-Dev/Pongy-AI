# Pongy AI 0.28.2 — накопительный исходный патч

## Установка поверх последней 0.27.0
1. Сделать резервную копию репозитория, базы, пользовательских файлов и настроек Render. Не удалять `.env`, секреты и базу.
2. Распаковать архив в корень проекта рядом с package.json с заменой совпадающих и добавлением новых файлов. Все изменения 0.28.0 + 0.28.1 + 0.28.2 включены; промежуточные патчи не нужны. Собственные изменения предварительно сравнить.
3. Закоммитить все файлы архива, включая MANIFEST.sha256. Дождаться GitHub-проверок и деплоя Render. Build: npm ci; Start: npm start.
4. Проверить /healthz, главную, версию 0.28.2, /privacy, /terms и /about без авторизации. Обновить вкладку.

Это исходники, не MSI/APK. Опубликованные нативные установщики остаются 0.20.0 и не переименованы: новые пакеты требуют отдельной сборки/проверки на устройстве. Нет очистки данных и разрушительной миграции.

## Известные ограничения
- Недоступные маршруты Render/TLS в России этим кодом не исправляются. Домен, сертификаты и CSP не ослаблялись ради обхода.
- Нет новых долговечных фоновых AI jobs, безопасной автосборки произвольных GitHub/ZIP-плагинов и автоматического удаления истории через месяц/сверх 100 сообщений. Для последнего нужно отдельное безопасное восстановление.
- Нет полного произвольного управления ПК/MAX, гарантированного распознавания любого шума/шёпота и эмоционального TTS.
- Нет фотореалистичного видеогенератора, звука или серверного Motion-рендера. Запись требует поддерживаемого браузера и активной вкладки.
- Кэш моделей может быть очищен браузером. Render ephemeral-диск не становится постоянным; подключения требуют устойчивой базы и стабильных ключей.
- Ошибки моделей и внешних API не исключены; платежи требуют настройки владельцем.
