# Прокрутка настроек и окно проверки — hotfix 0.23.1

## Установка

Распаковать ZIP **в корень полного проекта**, поверх уже применённых патчей 0.23.1, CI hotfix и Actions Node 24, с заменой одноимённых файлов. Дополнительной корневой папки в ZIP нет. Старые документы в `docs` оставлять: это история изменений, а не исполняемый код. Ничего предварительно удалять не требуется; `.env`, рабочую БД и другие файлы не трогать.

Перезапустить сервер и обновить страницу. Если браузер показывает старые стили, выполнить принудительное обновление страницы. Зависимости, workflow GitHub Actions, почта, версия приложения и нативные установщики этим патчем не меняются.

## Изменения

- Подпись активного ожидания голосового вызова: **«Позовите Pongy»**. Английская версия: **“Call Pongy”**. Состояния загрузки, ошибок и запроса доступа к микрофону сохранены. Механика распознавания не менялась.
- Вкладки настроек ограничены шириной окна, доступны прокруткой, колёсиком мыши и явными кнопками-стрелками. На телефоне сохранена нативная горизонтальная прокрутка. Стрелки не показываются, если все вкладки помещаются; крайние кнопки отключаются в конце списка.
- При выборе вкладки, открытии настроек и изменении ширины выбранный раздел становится видимым. Клавиатурная навигация Home/End и стрелками сохранена. Плавающий индикатор обновляет положение после изменения размеров.
- Содержимое настроек имеет независимую вертикальную прокрутку: длинные разделы не растягивают окно за пределы экрана.
- **Окно выбора типа проверки и её запуска открывается по центру экрана поверх остальных окон сайта.** Оно использует нативный модальный `dialog` в верхнем слое браузера и вынесено из прокручиваемого раздела. Даже обычный элемент с максимальным `z-index` не перекрывает его. Это заменяет прежнее требование размещать окно в левом верхнем углу.
- Ограничение высоты и прокрутка окна проверки сохранены. Escape закрывает окно, фокус возвращается на кнопку «Проверка». Во время выбора проверки фокус клавиатуры остаётся внутри диалога.

## Проверки

Новый сценарий `tests/settings-navigation-ui.cjs` проверяет русские названия разделов, доступность «Разработчик» **до автоматической прокрутки Playwright при клике**, прокрутку мышью и кнопками, клавиатуру, отсутствие горизонтального переполнения, положение индикатора, прокрутку содержимого, центрирование диалога с допуском менее 2px, верхний модальный слой, Escape и восстановление фокуса. Размеры: 1440×1000, 390×844 и 844×390.

Локальная среда: Chromium на Linux. Успешный прогон Firefox/WebKit здесь не заявляется; их проверку нужно повторить в GitHub Actions на Ubuntu. Исходники и тесты предыдущих обновлений сохранены, изменены только проверки намеренно заменённого поведения.
