# Проверки API и интерфейса — 0.27.0

## Автоматические проверки

- Полный набор модульных тестов: **743/743**, без пропусков. Включена проверка 1000 моделей, большого зашифрованного зеркала, привязки к пользователю и отсутствия секрета в статусе.
- HTTP-проверка: чтение повреждённой зашифрованной записи сообщает `USER_API_UNREADABLE` и не удаляет запись из базы.
- Новый браузерный сценарий API: **19 проверок**. Ввод ключа без blur, нормализация пробелов без зависания, провайдер и выбранная модель после перезагрузки, каталог из 160 моделей, согласие/черновик, поздние ответы после смены провайдера и аккаунта, очистка поля и отключение.
- Выдача продуктов: **26 проверок**. Включены реальная локальная выдача/отзыв/истечение доступа, центрирование и отсутствие обрезания на 1280×800 и 390×844, верхний слой над настройками, тёмная тема, фокус и Escape, режим уменьшенных анимаций.
- Существующие Chromium-сценарии настроек (51), навигации (45), Motion-оформления (15) и списка навыков (25) прошли отдельно.

- Полный прогон Chromium: **60/60 UI-наборов** прошли. Финальные проверки API (19), продуктов (26), настроек (51), навыков/плагинов (38), языка установщика (10) и Motion-оформления (15) также повторены после завершающих изменений.
- Проверка структуры и синтаксиса: **451 файл проекта, 267 JavaScript, 6 JSON**, `npm run check:release` прошёл.
- Исходный ZIP проверен распаковкой поверх побайтно восстановленной базы smart-pc-preview: **443 базовых файла**, итог **451 файл** совпадает с подготовленными исходниками. На восстановленной копии дополнительно прошли новый сценарий API (19) и выдача продуктов (26). В исходный архив не включены зависимости, базы, секреты, журналы, скриншоты или установщики.

Полный прогон включает существующие проверки навыков и языка установщика; тесты не отключались. Проверки в этом документе относятся к локальной среде Linux/Chromium, а не к новому запуску GitHub Actions.

## Ручной просмотр

Просмотрен снимок реального диалога выдачи на узком экране в тёмной теме после окончания переходов: окно по центру, поля и действия не выходят за края, основной интерфейс остаётся под модальным окном. Проверки используют Chromium, запущенный в Linux; это не проверка настоящего Windows WebView2 или Android WebView.

## Что не проверено

Firefox и WebKit в этом окружении не запускались. Ошибки из старого workflow не считаются устранёнными в CI до нового запуска на обновлённых исходниках. Внешние платежи, реальная доставка почты, доступность Render без VPN и рабочие ключи пользователей не использовались. Новые MSI/APK не собирались.
