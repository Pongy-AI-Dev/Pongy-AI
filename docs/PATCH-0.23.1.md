# Pongy AI 0.23.1 — исправляющий патч

## Применение

Этот ZIP — **инкрементальный патч поверх полного проекта с патчем 0.23.0**. В нём только новые и изменённые файлы, без дополнительной корневой папки. Он не заменяет полный репозиторий. Если установлен только исходный 0.22.2, сначала примените патч 0.23.0.

1. Сделайте резервную копию проекта, `.env` и рабочего `DATA_DIR`.
2. Остановите сервер. Распакуйте файлы ZIP в корень проекта с заменой одноимённых файлов, сохраняя вложенные пути. Не удаляйте остальные файлы.
3. Установите зависимости через `npm ci` (на сервере без тестов допустимо `npm ci --omit=dev`) и перезапустите сервер с прежним окружением и каталогом данных.
4. Для проекта с dev-зависимостями выполните `npm run check:release` и `npm test`. В браузере обновите страницу. Кэш оболочки и URL ресурсов обновлены до 0.23.1.
5. Войдите подтверждённым аккаунтом разработчика. Проверьте ограничения **из второго, обычного аккаунта**, а не из самого аккаунта разработчика.

Патч не содержит `.env`, паролей, БД, ключей подписи, `node_modules` или пересобранных MSI/APK. Нативные исходники и инструкции сборки получили номер 0.23.1; опубликованные старые установщики не переименованы и не выдаются за новые.

## Изменения

- Список изменений — первая кнопка справа в верхней панели. Единые размеры иконок, центрирование и области нажатия.
- Дополнительная строка `Pongy AI · 0.23.0` удалена; обычный нижний колонтитул остаётся и показывает текущую версию.
- Боковая панель без серого фона и жёстких разделителей. Обе кнопки Plus имеют одинаковые значок, подпись, геометрию и оформление выбранным акцентом.
- Сохранение имени и названия чата — галочки без круглого фона; клавиатурный фокус остаётся видимым.
- Раздел «Интерфейс»: одинаковый ритм полей, размеры подписей, подсказки, отступы и мобильные размеры элементов. Дополнительные плавные появления, раскрытия и закрытие списка изменений учитывают reduced motion.
- В серверный список разработчиков и резервные контакты добавлен `pongy.support@gmail.com`. Права выдаются только при `email_verified=1`. Адрес отзывов `pongy.suppot@gmail.com` из задания 0.23.0 не изменён: это другой адрес.
- Управление ограничениями блокирует конкурирующие изменения, читает результат обратно с сервера и не применяет устаревшие ответы. Ошибки отображаются внутри панели даже при отключённых всплывающих уведомлениях.
- Чёрный список нормализует пробелы/регистр, автоматически раскрывается после добавления, показывает пустое состояние и подтверждает удаление. Защита от блокировки подтверждённых разработчиков сохранена.
- Статус обслуживания учитывает `MAINTENANCE_MODE`; панель объясняет, если режим принудительно задан окружением и не может быть снят переключателем.

## Как работают ограничения

Остановка сайта и обслуживание действуют на обычных пользователей. Подтверждённые разработчики сохраняют доступ для восстановления сайта — отсутствие блокировки у разработчика не означает, что переключатель не работает. Чёрный список проверяется и при входе, и при аутентифицированных запросах уже открытого сеанса. Для глобальных ограничений используется локальная SQLite-база: **нужен постоянный `DATA_DIR`**. Несколько экземпляров с разными каталогами данных не делят эти ограничения; этот патч не внедряет распределённое хранилище. Причину проблемы на вашем развёрнутом сервере без доступа к нему установить нельзя.

## Голос: что действительно изменилось

Для ожидания имени сохранён полный локальный словарь Vosk: экспериментальная узкая грамматика исключена после проверки, потому что превращала обычную записанную речь в ложное «о ге». Уменьшен размер аудиоблока. Фонетические варианты «он ге», «о ге», «онги», «ольге» принимаются как обращение в начале фразы, отдельно либо перед поддерживаемой формой команды; неоднозначные варианты ждут окончательного результата, а не промежуточного слова. Фраза «Передай Ольге привет» не запускает захват. Пунктуация и регистр команды, включая ссылки, не переписываются.

После активации используется речевой движок браузера, если он доступен; при сетевой ошибке — прогретая офлайн-модель. Явно выбранный офлайн-режим сохраняется. При переходе на резерв больше не теряется флаг голосовой команды, автоматическая отправка и таймер тишины.

**Это не новый нейронный голосовой модуль уровня Алисы.** Используется имеющаяся Vosk-модель и системное распознавание браузера; акустическая модель не переобучена. Поддержка фонетических вариантов не гарантирует точного распознавания любого голоса и не исключает все ложные срабатывания. Браузерное распознавание после активации может передавать звук сервису поставщика браузера; ожидание имени локальное. Первый запуск требует загрузки модели.

Когда «Активация голосом» выключена, ожидание имени и микрофон отключаются. Когда включена — локальному поиску имени нужен открытый микрофон; после 10 секунд тишины завершается **захват команды**, а ожидание следующего обращения возобновляется. Это принципиальное отличие от выключения функции целиком. Обычный сайт не может гарантированно вывести свою вкладку поверх других приложений: действуют ограничения браузера и ОС. Нативный мост Windows требует отдельной сборки установщика. Секреты почты, работа на настоящем Windows и качество микрофона пользователя здесь не проверялись.

## Версии

Исправляющий выпуск: **0.23.0 → 0.23.1**. Новые существенные возможности — следующий minor (`0.24.0`), исправления и небольшие доработки — patch (`0.23.1`, `0.23.2`). Версии не складываются как десятичные числа. История изменений 0.23.0 сохранена в её документации; окно списка изменений показывает последний выпуск.
