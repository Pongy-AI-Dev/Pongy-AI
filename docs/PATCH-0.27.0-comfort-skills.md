# Pongy AI 0.27.0 — комфорт, голос и навыки

Дополнительный патч поверх **0.27.0 UI/mail hotfix**. Заменить файлы в корне и выполнить деплой Render. Новых npm-зависимостей нет. Старые навыки и плагины не удаляются. Если ранее включалось несколько навыков, при запуске сохраняется один выбор; остальные остаются в списке выключенными.

## Для пользователей
- Короткое уведомление об ошибке проверки почты с иконкой предупреждения.
- Отдельный язык голосового ввода, больше альтернатив распознавания, подсказки имени для совместимых браузеров. Текст не подменяется по придуманному словарю: нельзя честно гарантировать исправление любых акустических ошибок. Качество зависит от микрофона, языка и движка браузера.
- Подтверждение имени внутри поля, только после изменения.
- Аккуратные кнопки, палитра в одну строку, улучшенные экраны состояния и плавные блики маскота с учётом выбранного цвета.
- Крупный и мелкий режимы масштабируют размеры, отступы и текст вместе; обычный режим остаётся базовым. На телефонах сохраняется читаемый размер полей ввода.
- Быстрый список навыков по стрелке в меню `+`. Один выбранный навык показан блоком у поля ввода; сначала уберите его, затем выбирайте другой. Плагины можно сочетать.
- Новые навыки: «Переводчик» (пять вариантов перевода) и «Программист» (планирование, работа с доступным кодом и проверки). Это инструкции для доступного ИИ и инструментов, не установка новых программ и не обещание запуска кода.
- Текущая локальная дата и «завтра» вычисляются сервером и передаются модели; старые даты публикаций не должны подменять дату прогноза. Если нужного прогноза нет, ИИ должен это объяснить.
- Пользовательский список изменений краткий, без данных владельца и внутренних деталей разработки.

## Важные ограничения
Блокировку SMTP на стороне Render нельзя исправить в коде. Патч сокращает видимое сообщение об ошибке, но не имитирует успешную отправку. Для почты нужен доступный SMTP либо поддерживаемый Resend по HTTPS с действующим ключом и подтверждённым доменом отправителя; сайт можно оставить на прежнем адресе. Браузерные/push-уведомления работают независимо от почты при наличии необходимых разрешений и работающего сервера.

Доступ к подключённым сервисам использует существующие OAuth-разрешения и инструменты только по запросу пользователя. Наличие навыка не добавляет доступ к отсутствующему сервису, не обходится авторизация и не выдумываются результаты.

Источники сохраняются в соответствующем разделе; из прозы убран лишний рассказ о поставщике данных. Обязательная атрибуция и нужные для проверки ссылки не вырезаются. Политические ответы нейтральны и фактологичны; ложные заявления о модели и автоматическая замена содержательного ответа шуткой не добавлены.

Версия сайта/исходников остаётся 0.27.0 (дополнительный hotfix). Исторические записи не переименованы. Опубликованные MSI/APK действительно собраны как 0.20.0: их имена, подписи, хеши и метаданные **не подменяются**. Для новых нативных версий нужна настоящая пересборка и публикация подписанных установщиков. В интерфейсе отдельно указаны версия сайта и версия нативной оболочки.
