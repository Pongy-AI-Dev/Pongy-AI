# Pongy AI 0.24.3 — напоминания на границе минуты и окно Connections

## Установка

Это добавочный ZIP поверх полной версии 0.24.2 (reminder-flow). Сделайте резервную копию, распакуйте в корень проекта с заменой одноимённых файлов. Старые docs, .env, базы и пользовательские данные не удалять. Разверните обновлённые сервер и фронтенд, затем обновите страницу Ctrl+F5. Если фронтенд и API размещены отдельно, обновить нужно оба соответствующих развёртывания. Новых npm-зависимостей нет.

## 1. Сохранение ручного напоминания при смене минуты

В присланном Firefox-логе тайм-аут относится ко второму сохранению, из конкретной заметки: тест ждал закрытия формы. Сам HTTP-ответ в старом тесте не выводился.

Воспроизведён дефект с тем же ожидающим шагом: ручная форма предлагала текущую минуту. При смене минуты, особенно даты, до нажатия «Напомнить» сервер закономерно возвращал REMINDER_PAST, а форма оставалась открытой с ошибкой. Это не обход серверной проверки времени и не проблема OAuth.

Теперь ручная новая форма предлагает время с запасом пять минут, округлённое вверх до целой минуты. Дата вычисляется из этого же момента, поэтому 23:59:59 даёт 00:05 следующего дня. Сохранение по-прежнему требует подтверждения.

НЕ изменяются:
- дата/время, явно извлечённые из команды пользователя;
- пустое время в неполном запросе «Сделай напоминание» или «через X»;
- существующие даты и время при редактировании сохранённого напоминания;
- серверный запрет сохранения действительно прошедшего времени.

Регрессия фиксирует время браузера и сервера на 23:59:59, открывает форму из заметки, затем переводит время на 00:00:01 и сохраняет. На прежнем коде получен HTTP 400 REMINDER_PAST. После исправления — успешный ответ и одна заметка-связанная запись. При сбое тест сразу показывает HTTP-ошибку, статус и native validity полей, вместо одного непрозрачного ожидания закрытия.

## 2. Центрирование Connections и настройки зова

Убран процентный translate, привязанный к размеру самого окна. Native dialog использует фиксированные границы viewport, height: fit-content, автоматические отступы и ограничение высоты. Окно остаётся в верхнем модальном слое, длинный каталог прокручивается. То же правило применяется к окну настройки зова, использующему этот CSS-класс. Анимация входа сохранена.

Проверка геометрии теперь ждёт кадров layout и завершения конечной анимации элемента, а не полагается только на 350 мс. Требование центра и границ осталось строгим: допуск центра менее 2px, окно и содержимое не должны выходить за viewport по ширине. При ошибке выводятся размеры, viewport, translate/transform и состояние анимации. Дополнительно проверены краткая панель провайдера, ширина 320px и горизонтальный экран 844×390, а также доступная прокрутка длинного каталога.

Само падение WebKit локально пока не воспроизведено: на рабочем компьютере не хватает необходимых библиотек GTK/GStreamer/ICU/NSS для этих сборок Firefox/WebKit. Загрузка браузеров не заменяет запуск. Подтверждение результата именно в этих движках требует нового прогона GitHub Actions; проверки не отключены и не помечены как допустимые ошибки.

Сетевой и криптографический код Connections, а также OAuth-ключи не изменены. Сообщения «Почта не настроена» в присланных логах относятся к почтовому отправителю тестового сервера; сами по себе не являются причиной падения проверки геометрии или закрытия формы.
