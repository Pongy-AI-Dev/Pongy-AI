# Проверки восстановленной сборки 0.28.2

Выполнены заново после восстановления исходников из сохранённых проверенных снимков 0.28.1 и 0.27.0 и правовых текстов из сохранённого DOCX. Это пересобранный архив, его байты/контрольная сумма могут отличаться от утраченного.

- Полный npm test: **776/776**, 0 failed, 0 skipped.
- Chromium: **9/9** выбранных UI-наборов: legal-pages, update-028, response-recovery, api-persistence, startup, products, motion-video, skill-menu, product.
- Legal-pages проверяет документы без JavaScript на ширинах 320/390/1280, публичные ссылки и отсутствие горизонтального переполнения: **36** проверок.
- Остальные выбранные наборы проверяют настройки/модель, fresh browser restoration, Plus renewal, Smart PC entry, API, восстановление ответа, реальный Motion/MKV export, сенсорное меню, аккаунт и поддержку.
- Перед упаковкой выполняются check:release (структура, синтаксис, полный SHA256 manifest), ZIP CRC и проверка точного воспроизведения полного состава исходников при наложении патча на последнюю сохранённую 0.27.0.

Полный набор из 63 UI-suite подряд для этой сборки не запускался. Firefox/WebKit и реальные Windows/Android-устройства не проверены в этом прогоне. Старые отчёты относятся к своим версиям и не подменяют проверки текущей.

Не проверялись реальные аккаунты/секреты Render, одобрение Google, реальные платежи и доступ из сетей российских операторов. Тестовые upstream responses не доказывают production-доступность внешних моделей. Безошибочность всего продукта и юридическое соответствие не гарантируются.
