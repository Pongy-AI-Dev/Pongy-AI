# Исправление загрузки и проверок — 0.27.0

Патч накладывается поверх smart-pc-preview 0.27.0. Резервная копия проекта и базы обязательна. Файлы базы, секреты и сохранённые данные не удаляются.

## Исправлено

- При открытии каталога навыков очищаются карточки предыдущего каталога. Раньше одинаковое число карточек плагинов и навыков позволяло увидеть старый список до завершения запроса; это объясняло `weather missing` в Chromium. Тест ждёт содержимое именно каталога навыков, проверки не отключены.
- Тест языка установщика извлекает только выражение `nativeScript()`, а не захватывает следующий C++ код до `AddScriptToExecuteOnDocumentCreated`. Именно ошибка извлечения вызывала `Unexpected non-whitespace character after JSON`; она не доказывала ошибку JavaScript внутри самого приложения.
- Скрипты сайта загружаются с `defer`: загрузка файлов идёт параллельно, выполнение сохраняет порядок зависимостей. Парсер HTML больше не ждёт последовательной загрузки всех скриптов.
- Первый небольшой startup-guard запускается до CSS. Если запуск не завершён за 12 секунд или не загрузился JS интерфейса, появляется понятный экран с повторной загрузкой. Поздний успешный запуск убирает этот экран. Cookies, история, API-ключи и черновики не очищаются.
- У установленной автономной оболочки навигация ограничена 20 секундами. При зависании сети или HTTP 5xx используется только общедоступный offline-экран, без кэширования личных API-ответов. При первом посещении, когда Service Worker ещё не установлен и сам домен недоступен, этот механизм помочь не может.
- Windows: переход на сайт выполняется после завершения регистрации нативного скрипта WebView2; исправлен возможный порядок-гонка. На старте видна системная надпись загрузки, а не пустой рендерер; зависшая навигация через 30 секунд останавливается и показывает встроенный экран повторного подключения.
- Android: индикатор загрузки с отменой, таймаут 30 секунд и переход к локальному экрану при ошибке главного документа/HTTP/SSL. Проверка сертификатов не отключается.
- Тексты восстановления больше не утверждают, что у пользователя точно отключён интернет: недоступен может быть и сам сайт/сетевой маршрут.

## Как применить

1. Распакуйте ZIP с заменой файлов в корень текущего проекта после smart-pc-preview. Не удаляйте базу и переменные окружения. Не требуется менять платёжные или OAuth-ключи.
2. Разверните сайт и сервер. Перезагрузите страницу обычным способом. Не очищайте данные браузера ради этого исправления.
3. Для Windows используйте отдельный portable ZIP из этого исправления либо пересоберите MSI ручным workflow `Build Windows installer (manual)`. Полностью закройте старую Pongy перед запуском нового EXE; держите EXE и WebView2Loader.dll вместе. Нужен официальный Microsoft Edge WebView2 Runtime.
4. Для Android необходимо пересобрать APK из native/android/build.sh с исходным ключом подписи. В этом исправлении готовый подписанный APK не публикуется. Новый случайный ключ не подходит для безопасного обновления установленного приложения.
5. Изменения нативного запуска НЕ попадут в старый установленный MSI/APK от одного лишь обновления сайта. Предварительная сборка Windows по-прежнему неподписанная; опубликованные приложения 0.20.0 не переименовываются и каталог загрузок не подменяется.

## Работа только с VPN

Этот патч не заявляет обход сетевых блокировок. Во время проверки из среды разработки сайт `/`, `app.js`, `app-config.js` и API `/healthz` отвечали 200 примерно за 0.2–0.4 секунды. Это не измерение из сети пользователя и не доказательство отсутствия региональных проблем.

Без VPN сравните доступность:

- https://pongy-ai.devs.surf/
- https://pongy-server.onrender.com/healthz — ожидается `{"status":"ok"}`.

Если API работает, а домен сайта нет — отдельно проверяйте DNS/маршрут/CDN домена. Если оба доступны только с VPN — проверяйте маршрут к обоим адресам. Чистые логи Render не исключают проблему: запрос мог вообще не дойти до сервера. Автоматически менять домен приложения, отключать TLS-проверки или переносить секреты на другой origin нельзя. Для постоянного решения может потребоваться другой доступный домен/хостинг и согласованная настройка OAuth, cookies и CORS.

Уточняйте отдельно Windows/Android, версию установленного пакета и наличие белого экрана с включённым VPN. Полное управление любыми окнами Windows и отправка сообщений MAX в этот сетевой патч не входят.
