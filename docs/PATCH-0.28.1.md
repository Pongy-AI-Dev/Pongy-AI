# Pongy AI 0.28.1 — Matroska и Google OAuth

Накопительный исходный патч включает изменения 0.28.0 и доработку MKV. Распаковать в корень последнего репозитория 0.27.0 или 0.28.0 с заменой файлов, добавить новые файлы в GitHub и дождаться деплоя Render. Сначала сохранить резервную копию. `.env`, базу и секреты не удалять. Это не MSI/APK; нативные установщики по-прежнему требуют отдельной сборки.

В ZIP-проекте Motion открыть index.html → выбрать **MKV (Matroska)** → «Экспорт видео» → «Скачать готовое видео». MKV формируется локально из реально записанного WebM: перестраивается заголовок EBML с DocType `matroska`, видеопакеты сохраняются без потери качества. Это не переименование расширения и не генерация новых деталей изображения. Нужна поддержка записи WebM; вкладку нельзя скрывать до завершения. Звук, серверный рендер и конвертация любых пользовательских видео этим изменением не добавляются.

[Пошаговая инструкция Google OAuth](GOOGLE-OAUTH-PONGY.md) разделяет вход Google и подключение Drive/Gmail/Calendar. Не меняйте переменные Render наугад: сначала сверьте три несекретных URL. Публичный Gmail требует restricted-scope проверки и соответствующих требований Google; тестовый режим не заменяет её.

[Объём и оставшиеся задачи предыдущей части](PATCH-0.28.0.md). Этот патч не объявляет весь первоначальный запрос выполненным. Следующие крупные задачи — безопасная система GitHub/ZIP-плагинов, долговечные фоновые AI-задачи, управляемая политика хранения истории с восстановлением и голосовые улучшения на реальных устройствах.
