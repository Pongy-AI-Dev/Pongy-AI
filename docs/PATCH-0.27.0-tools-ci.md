# Pongy AI 0.27.0 — CI: список инструментов

Точечное исправление поверх **0.27.0 skill-menu hotfix**. Заменить файлы из архива в корне репозитория, закоммитить и повторно запустить GitHub Actions. Изменяются только две UI-проверки, эта инструкция и контрольные суммы. Код приложения, интерфейс, зависимости и база не меняются; для исправления тестов деплой Render не требуется.

Причина: после разделения кнопки «Навыки» и кнопки-стрелки основной пункт расположен в `.composer-skills-row`. Старый селектор `#composerMenu>button` пропускал этот пункт. Оба теста теперь учитывают его внутри строки, по-прежнему проверяют точный список из шести основных инструментов в правильном порядке и отдельно проверяют наличие стрелки с привязкой к `quickSkills`. Проверки не отключены, таймауты не увеличены.
