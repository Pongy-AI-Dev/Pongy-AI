# Pongy AI 0.28.0 — проверяемое обновление исходников

> Исторический объём первой части. В 0.28.1 уточнённый пользователем формат «Матрёшка» реализован как MKV; см. [патч 0.28.1](PATCH-0.28.1.md).

## Установка

Это **исходный патч**, не установщик и не программа для запуска на компьютере. Распакуйте в корень актуального репозитория Pongy AI с заменой одноимённых файлов, сохраните изменения в GitHub и дождитесь деплоя Render. Не удаляйте `.env`, базу, каталог данных и секреты. Перед обновлением сохраните резервную копию данных. Новые файлы из архива также нужно добавить в GitHub.

Проверки после установки: `npm ci`, `npm test`, `npm run check:release`, `npm run test:ui` с установленными браузерами Playwright. Полный MANIFEST описывает исходники, а не персональные данные или node_modules. ZIP содержит только изменённые/новые файлы; он не заменяет полный репозиторий.

Windows/Android: исправления нативных исходников требуют отдельной сборки и установки новых MSI/APK. Опубликованные старые файлы 0.20.0 не переименованы в 0.28.0.

## Что изменено

- Чтения API и записи имеют независимые лимиты 200/мин на IP: фоновая загрузка метаданных не блокирует сохранение настроек. Дополнительные строгие лимиты входа, писем, ИИ и загрузок сохранены.
- Режим мышления, поиск и выбор модели сохраняются в серверных настройках и локальном аккаунтном хранилище. Смена аккаунта не переносит настройки предыдущего пользователя.
- Сенсорное меню навыков закрепляется после касания: mouseleave и focusout без нового фокуса не закрывают его. Escape, нажатие снаружи и уход фокуса в другое поле по-прежнему работают.
- Метаданные подключений и каталоги дополнений предварительно загружаются и повторно используются в текущей сессии. Секреты OAuth не помещаются в браузерный кэш. Подключения перепроверяются сервером.
- Почта аккаунта доступна для чтения под именем; убрана сводка дат подписок. Исправлены двойная иконка скачивания, компактность ошибок/вложений, акцент маскота, оформление API-ключа, мягкие переходы с поддержкой reduced motion.
- Plus скрыт при активной подписке, кроме последних 72 часов. В этот период показано продление: 190 ₽ перечёркнуто, цена 120 ₽. Скидку рассчитывает сервер для текущего аккаунта, а не клиент. Для USD используется курс и округление вверх до чётного целого доллара. После истечения подписки применяется обычная цена. Оплата доступна только при настроенных ключах платёжного провайдера; ввод номера карты в фиктивную форму удалён.
- Веб-версия показывает описание Smart PC и переход к покупке; исполнение локальных команд остаётся функцией Windows-приложения, а не браузера.
- Переключение настроенных моделей расширено до ограниченного пула (по умолчанию 32, максимум 64), временные отказы допускают один дополнительный повтор провайдера до появления текста/действий. Общий тайм-аут, защита от двойного выполнения инструментов и запрет неразрешённых платных провайдеров сохранены. Очередь глобальной нагрузки ограничена 32 ожидающими запросами и 15 секундами; занятость возвращает Retry-After.
- Добавлены русские предметные опоры для изображений и инструкция отвечать на языке последнего запроса. Это улучшения подсказок, не гарантия безошибочности внешних моделей.
- Видео анализируется по 30–60 кадрам, сгруппированным в три листа; в сообщении показывается один представитель, а не все листы. Одновременно можно отправить одно видео. Анализ не заменяет покадровое распознавание, исходный большой файл не гарантированно хранится на сервере.
- Публичные архивы речевых моделей сохраняются в CacheStorage и повторно используются после перезапуска worker. Ошибка квоты не ломает онлайн-загрузку. Браузер вправе удалить свой кэш; постоянное офлайн-хранение не обещается.
- Motion: до 120 секунд, 60 fps и 120 слоёв; артикулированный stickman/walk; увеличен битрейт. Экспорт MP4 доступен только при реальной поддержке MediaRecorder MP4/H.264. Иначе — честное сообщение и WebM, без переименования расширения. Это декларативная Canvas-анимация, не фотореалистичный видеогенератор. Запись требует открытой видимой вкладки.
- Android-исходники учитывают системные панели, вырезы и клавиатуру; нужен отдельно собранный APK и проверка на реальном устройстве.

## Что нельзя исправить одним исходным патчем

### Google OAuth

Сообщение «приложение не прошло проверку Google» — ограничение OAuth-проекта владельца. В Google Cloud/Google Auth Platform проверьте Audience (Testing/Production), список Test users, Branding/Authorized domains, Data Access и точные OAuth redirect URI из конфигурации сервера. Для публичного доступа к чувствительным/ограниченным Drive/Gmail scopes может требоваться проверка Google и дополнительные требования. Не отключайте защиту и не просите пользователей обходить предупреждение. До допуска используйте разрешённые тестовые аккаунты либо оставляйте интеграцию выключенной.

### Render и сеть

SSL connection timeout / ERR_CONNECTION_RESET до завершения TLS не исправляются JavaScript, CSS, CSP или health check. Успех из части городов не доказывает доступность у всех провайдеров. Нужны ответ Render/оператора, проверка маршрута и DNS/сертификата; без переноса/проксирования нельзя гарантировать восстановление. Домен патч не меняет. HTTPS и CSP не ослаблены.

### Сохранность подключений

OAuth-токены хранятся зашифрованными в SQLite. Постоянные SESSION_SECRET/JWT_SECRET и сохранность DATA_DIR/базы необходимы. Если база/ключи потеряны при redeploy на эфемерном диске Render Free, браузерный кэш не восстановит подключения. Этот патч не добавляет облачную миграцию токенов и не делает бесплатный диск постоянным.

## Не включено в эту поставку

Не реализованы: автосборка произвольных GitHub/ZIP-плагинов; необратимое автоматическое удаление истории; долговечные серверные фоновые задачи; конвертация произвольных загруженных видео, MOV/неопределённый «maw»; гарантированное распознавание шёпота/шума и эмоциональная озвучка; полностью автономное управление всеми приложениями ПК; новая модель фотореалистичного видео. Автоматическое исполнение чужого кода требует отдельной изолированной среды. История не удаляется этим патчем, чтобы не подменять резервирование потерей данных.

Нельзя гарантировать «каждый пиксель анимирован» без ущерба мобильной скорости/доступности: анимируются переходы и активные состояния, учитывается reduced motion. Нельзя гарантировать нулевую задержку сети, идеальное понимание любого запроса или отсутствие всех ошибок.
