# Pongy AI 0.29.2 — поиск и модельные подключения

Дата: 21 ноября 2026 года

## Поиск

- Для Brave Search, DuckDuckGo HTML и Bing RSS включён строгий Safe Search.
- Сохранены ограничения на публичные HTTPS-источники, блокировку внутренних адресов, безопасные перенаправления и лимиты размера ответа.
- Поисковые сниппеты по-прежнему не считаются прочитанной страницей; для подтверждения сведений используется отдельное чтение источника.
- Ошибка Tavily не переключает запрос незаметно на другой платный сервис.

## ГДЗ

- Проверены сценарии поиска упражнения без обязательного предварительного указания автора и года.
- Сохраняется проверка совпадения номера задания и учебника; сниппет не используется как доказательство условия.
- Если публичную страницу прочитать не удалось, система должна честно запросить текст задания, а не придумывать условие или ответ.
- Подтверждено тестами: русские и английские запросы, контекстное уточнение автора, неизвестная редакция, неподтверждённая страна и номера вида `3.345`.

## Модели и API

- Реестр личных API расширен до 21 провайдера.
- Добавлен Alibaba Cloud Model Studio для OpenAI-совместимого Chat Completions API через региональный Singapore endpoint. API-ключ должен относиться к тому же региону; endpoint не является универсальным для ключей из других регионов.
- Каталог моделей загружается у выбранного провайдера; модель принимается только если она реально присутствует в возвращённом каталоге.
- Ключи остаются на сервере, хранятся в зашифрованном виде и не возвращаются клиенту.
- Наличие интеграции в реестре и успешные mock-тесты не означают, что провайдер активирован у пользователя или что его квота доступна.

## Ограничения текущей проверки

На локальной рабочей копии отсутствуют настроенные серверные ключи OpenRouter, Gemini, DeepSeek, Tavily, Brave и Cloudflare. Поэтому живые каталоги моделей и inference-запросы с этими учётными данными проверить не удалось. Платные запросы не запускались. Для личных API ключи должны быть подключены пользователем через интерфейс Pongy AI; проверка доступности требует действующего ключа и соответствующего региона/квоты.
