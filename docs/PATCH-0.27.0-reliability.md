# Pongy AI 0.27.0 — reliability patch

## Установка

Распакуйте архив в корень проекта поверх всех предыдущих патчей 0.27.0, включая smooth-motion-hotfix. Это небольшой инкрементальный патч: он содержит изменённые файлы, не весь проект. Обновите и сервер, и публикацию `public`. Структура БД совместима; удалять данные и настройки не нужно. После публикации перезагрузите сайт/приложение. Service worker обновляется браузером; при уже открытых старых вкладках закройте их и откройте сайт снова.

- Тишина (`no-speech`) больше не является фатальной ошибкой маскота; запись возобновляется с ограниченной задержкой. Ошибки разрешения микрофона не скрываются. В офлайн-движке ошибка обрабатывается до завершения записи, чтобы не отправить незаконченный запрос.
- Вкладки и service worker используют общий журнал доставки IndexedDB. Он хранит только идентификаторы и время событий (до 7 дней), не текст, звук или ключи. Повтор после перезагрузки подавляется; неудачную доставку можно повторить. При недоступном IndexedDB остаётся защита в памяти, без гарантии между перезапусками. Сбой браузера ровно между показом и записью подтверждения по-прежнему может дать повтор: абсолютной гарантии exactly-once нет.
- Сервер хранит принятую галочку согласия и до 100 записей каталога моделей внутри существующего зашифрованного конфига. Выбранная модель сохраняется первой. При отсутствии локальной копии ключа поле пустое со статусом «Ключ сохранён на сервере»: секрет **не возвращается** из API. Для старых подключений восстанавливаются выбранная модель и ранее принятое согласие. Для восстановления всего старого каталога загрузите модели заново.
- Оценка сервиса ограничена настоящим мостом приложения/его User-Agent. Параметры ссылки и старая запись `pongy_app_client` больше не включают её на сайте. Обращения в поддержку и жалобы на ответы сохранены.
- Явная настройка полной анимации учитывается при системном уменьшении движения; выбранное пользователем уменьшение сохраняется. Анимации не включаются принудительно против настройки пользователя.
- Добавлены варианты повторных приветствий и ответов о Pongy. Для короткого вопроса «Ты секретный DeepSeek?» после обсуждения Тайваня предусмотрена локальная контекстная шутка; в подсказке модели также разрешена шутка «не секретный ли я DeepSeek?», без ложных заявлений о фактическом провайдере и без замены содержательного ответа шуткой. Точный ответ внешней модели не гарантирован.

## Windows: требуется новая сборка

Исходник оболочки поддерживает F11 для входа/выхода из полноэкранного режима и Escape для выхода, с восстановлением положения окна. Команды принимаются только от доверенного домена. Добавлены установка курсора клиентской области и явный текстовый курсор/каретка в полях. Исчезновение указателя в конкретной системе нужно дополнительно проверить на настоящем Windows/WebView2; общая гарантия исправления без воспроизведения невозможна.

**MSI/APK в архиве нет.** Опубликованные пакеты 0.20.0 не переименованы и не заменены. Исходники остаются 0.27.0. Изменения сайта доступны приложению после обновления страницы; изменения оболочки F11 — только после установки новой сборки.

Для пересборки Windows загрузите патч в GitHub, откройте **Actions → Build Windows installer (manual) → Run workflow**. После успешной сборки скачайте артефакт `Pongy-AI-0.27.0-windows-unsigned`. Сценарий скачивает официальный WebView2 SDK и WiX, запускает существующий `build.ps1` и прикладывает SHA-256. Он не публикует релиз автоматически. Установщик неподписанный: проверка Windows SmartScreen возможна. Прежде чем менять ссылки и сведения о загрузках, проверьте MSI на Windows, вычислите размер/хеш и обновите манифест загрузок фактического файла. В этой Linux-среде Windows-сборка и запуск установщика не выполнены. Android этим workflow не пересобирается.

Не меняйте `JWT_SECRET`: существующие сохранённые ключи зашифрованы с его использованием. На Render используйте постоянное хранилище/настроенное облачное зеркало; патч не может сохранить удаляемую при каждом деплое базу без хранилища.
