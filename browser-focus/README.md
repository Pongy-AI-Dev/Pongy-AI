# Pongy — Wake Focus (Chrome / Edge)

Дополнительный компонент для автоматической активации вкладки после голосового зова. Без расширения обычный сайт не имеет надёжного права переключать вкладки.

1. Обновите сайт до 0.26.0 и распакуйте отдельный архив расширения в постоянную папку (не запускайте JavaScript вручную).
2. Откройте `chrome://extensions` (Chrome) или `edge://extensions` (Edge).
3. Включите режим разработчика → «Загрузить распакованное» → выберите эту папку, где лежит `manifest.json`.
4. Откройте значок **Pongy — Wake Focus** в меню расширений и включите **«Разрешить переключение вкладки»**. По умолчанию это выключено.
5. Перезагрузите вкладку `https://pongy-ai.devs.surf`, включите голосовую активацию и разрешите микрофон. Если используете персональный зов, настройте его на своём микрофоне.
6. Перейдите на другую вкладку того же профиля браузера и позовите Pongy. Когда сайт распознает зов, расширение активирует исходную вкладку и запросит фокус окна; сайт начнёт обычный голосовой запрос при появлении вкладки.

Расширение не распознаёт звук само: исходная вкладка должна оставаться открытой и не быть выгруженной браузером. Оно не пробуждает спящий компьютер, не обходит запреты микрофона/ОС и не гарантирует распознавание голоса. Не обещается работа в закрытом браузере, Safari/Firefox или свёрнутом мобильном браузере. Даже запрос фокуса окна расширением может ограничиваться ОС.

Разрешения: `storage` для одного переключателя; доступ только к `https://pongy-ai.devs.surf/*` для проверки URL исходной вкладки. Нет разрешений `tabs` на чтение всех вкладок, микрофона, чтения сообщений, удалённого кода, произвольной навигации или `<all_urls>`. Запросы принимаются только от этого origin и только из вкладки-отправителя; адрес вкладки перепроверяется перед переключением. Не более одной попытки раз в 4 секунды.

Поле `key` в manifest — открытый публичный ключ для постоянного ID распакованного расширения. Это НЕ OAuth/API-секрет. Не удаляйте/не меняйте его: сайт обращается к соответствующему ID. Для публикации в Chrome Web Store нужен отдельный релиз и согласование ID с сайтом. Расширение не подписано для магазина и не устанавливается этим патчем автоматически.

Отключить: снять переключатель в окне расширения или удалить расширение. Сайт продолжит обычный сценарий с попыткой фокусировки и уведомлением. Не включайте расширение, если не хотите, чтобы Pongy мог менять активную вкладку.
