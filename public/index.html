Расширение браузера

Установите расширение для переключения вкладки по зову в настольных Chrome и Edge.

Скачать расширение для Chrome / Edge
Как установить
  1. Распакуйте ZIP в постоянную папку.
  2. Откройте страницу расширений: chrome://extensions / edge://extensions.
  3. Включите режим разработчика → «Загрузить распакованное» → выберите папку с manifest.json.
  4. В окне расширения включите «Разрешить переключение вкладки».
  5. Перезагрузите Pongy, включите активацию голосом и разрешите микрофон.

Расширение не устанавливается автоматически. Вкладка Pongy должна оставаться открытой и не быть выгруженной браузером. Ограничения микрофона и ОС сохраняются; Safari, Firefox и мобильные браузеры не поддерживаются этим расширением.
