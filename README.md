# Pongy AI

Pongy AI — персональный ИИ-помощник для общения, учёбы и повседневных задач.

## Что умеет

- Отвечать на вопросы и помогать разбираться в сложных темах.
- Работать с текстами, документами и файлами.
- Общаться голосом и распознавать речь.
- Помогать с поиском информации, программированием и творческими задачами.
- Подключать дополнительные модели, инструменты и сервисы.

## Где пользоваться

- **Сайт:** https://pongy-ai.devs.surf/
- **Windows:** приложение в формате MSI.
- **Android:** приложение в формате APK.
