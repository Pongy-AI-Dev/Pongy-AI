# Pongy AI

**Версия 1.1.1**

Веб-приложение для общения с ИИ. Чистый интерфейс, история диалогов и потоковые ответы — в одном месте, на компьютере и телефоне.

## Возможности

- Общение с бесплатными текстовыми моделями OpenRouter.
- Переключение на резервную модель при ошибке или недоступности основной.
- История чатов, поиск по названиям, закрепление, переименование и удаление.
- Потоковое отображение ответов и форматирование Markdown.
- Светлая и тёмная темы, русский и английский интерфейс.
- Адаптивная панель чатов и управление с клавиатуры.
- Регистрация по почте, восстановление пароля и вход через Google после настройки соответствующих сервисов.
- Серверное хранение ключа ИИ: посетителям не нужно вводить свой ключ.

## Характеристики

| Параметр | Значение |
| --- | --- |
| Сервер | Node.js 22+, Express |
| База данных | SQLite |
| Интерфейс | HTML, CSS, JavaScript |
| ИИ | OpenRouter API |
| Авторизация | HttpOnly cookie |
| Защита | Хеширование паролей, ограничение запросов, CSP, очистка HTML |

## Установка

Установите Node.js 22+ и скачайте проект.

```bash
npm ci
cp .env.example .env
```

В Windows вместо `cp` используйте `copy .env.example .env`.

Укажите в `.env` ключ `OPENROUTER_API_KEY` и запустите приложение:

```bash
npm start
```

Откройте **http://localhost:3000**.

Для регистрации и восстановления пароля настройте `RESEND_API_KEY` и `MAIL_FROM`. Для входа через Google — `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` и `GOOGLE_CALLBACK_URL`.

### Render

- Команда сборки: `npm ci`.
- Команда запуска: `npm start`.
- Переменные окружения: `NODE_ENV=production`, `FRONTEND_URL` — адрес сайта, `OPENROUTER_API_KEY` — серверный ключ ИИ.
- База данных: постоянный диск и `DATA_DIR`, указывающий на его путь.
- При отдельном размещении сайта и API: `PUBLIC_API_ORIGIN`, `CORS_ORIGINS`, `COOKIE_SAMESITE=none`; оба адреса должны использовать HTTPS. Браузер должен разрешать cookie API.

Для отдельного хостинга интерфейса используйте содержимое папки `public/`.
