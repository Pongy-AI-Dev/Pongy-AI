# Pongy AI

**Версия 0.16.2** · Веб-приложение для компьютеров и телефонов.

Pongy AI — персональный помощник с потоковыми ответами, вложениями и историей диалогов. Простой интерфейс помогает сосредоточиться на вопросе, а не на настройках.

## Приложения

Кнопка «Скачать приложение» в шапке и настройках предлагает настоящий Windows x64 MSI или подписанный Android APK. Издатель пакетов: **Pongy AI Dev**. Клиенты открывают официальный сайт `https://pongy-ai.devs.surf/`: Windows использует отдельное окно Edge (при его отсутствии — браузер по умолчанию), Android — Custom Tabs поддерживающего браузера или обычную браузерную вкладку. Требуется интернет. Это онлайн-клиенты, а не локальная нейросеть; квоты и скорость серверного ИИ не меняются.

MSI не имеет доверенной Authenticode-подписи, поэтому Windows может показывать неизвестного издателя. APK подписан постоянным самостоятельным ключом; Android может запросить разрешение установить пакет из браузера. Секретный ключ не входит в репозиторий или публичные загрузки. Подпись APK и суммы пакетов проверены при сборке, но это не заменяет проверку установки на реальных устройствах.

Сайт в клиентах обновляется с сервером. Для нового нативного пакета показывается предложение обновления; установка требует подтверждения ОС. Загрузка не выдаётся за завершённую установку. `public/downloads/releases.json` содержит версию, публичный отпечаток сертификата и SHA-256 пакетов. `native/` содержит исходники и сборочные скрипты; для будущих APK необходимо использовать тот же закрытый ключ подписи. iOS и Windows ARM не являются целевыми платформами этого выпуска.

## Возможности

- Журнал реальных действий: план, обращения к инструментам, результаты синтаксической проверки и прикреплённые файлы. План не означает выполненную работу; внутренние рассуждения модели не показываются.
- Готовые именованные файлы из завершённых блоков кода, подсветка синтаксиса и чтение сохранённых исходников текущего чата по частям. Проверка JavaScript/JSON не запускает код и не гарантирует правильность программы; другие языки явно помечаются как непроверенные.

- Отдельное пространство заметок: поиск, закрепление, переименование, вложения и форматирование выделенного текста. Сохранение на устройстве и синхронизация с сервером; конфликты правок не перезаписывают черновик молча.
- ИИ читает заметки по запросу и предлагает изменения, которые применяются только после подтверждения. При замене текста оформление заменяется; вложения сохраняются.
- Выбранный режим виден в отправленном сообщении и передаётся модели. Незавершённый ответ отмечается предупреждением.
- Сохранённая история доступна ИИ по частям для точного цитирования. Окно контекста и число действий ограничены; одновременная загрузка всей истории любого размера не гарантируется.

- Формулы KaTeX, блоки кода с копированием/скачиванием и боковым предпросмотром.
- Изолированный запуск HTML/JavaScript по подтверждению; остальные языки доступны для чтения, не исполняются сервером.
- Лайки, несколько закреплённых сообщений, сворачивание длинных ответов.
- Предложения ИИ изменить тему/язык, открыть чат или включить встроенный фоновый звук — только после подтверждения.
- Голосовой ввод: быстрый браузерный движок и автоматический резерв Vosk на устройстве (русский/английский), без установки браузерных языковых пакетов. При первом резервном запуске загружается модель около 40–45 МБ; требуется разрешение микрофона. Индикатор громкости использует реальный звук.
- Локальные ресурсы KaTeX распространяются по лицензии MIT (public/vendor/katex/LICENSE).


- Бесплатные модели OpenRouter и автоматическое переключение при сбоях.
- Анализ изображений через доступные модели с поддержкой vision.
- Вложения: изображения, текст, исходный код, PDF, DOCX и ZIP-проекты.
- Поиск по необходимости через Tavily или Brave Search API; чтение публичных HTTPS-страниц.
- Поиск Wiki-страниц и фотографий Wikimedia Commons с указанием авторов и лицензий.
- Раскрываемый список «Источники (N)» под ответом.
- Создание и скачивание текстовых файлов, исходного кода и ZIP-проектов.
- Платная генерация изображений отключена, пока Plus не активен; бесплатный генератор не подключён.
- Уточнение сообщения через плашку над полем ввода.
- История по датам: закрепление, переименование, поиск и удаление чатов.
- Дополнительный контекст из других чатов — по желанию пользователя.
- Светлая и тёмная темы, русский и английский интерфейс, плавные анимации.
- Вход по почте, подтверждение адреса, восстановление пароля и Google после настройки авторизации.
- Облачное сохранение через Firestore либо локальное хранение в SQLite.
- API-ключ ИИ хранится на сервере. Посетителям вводить ключ не нужно.

## Характеристики

| Параметр | Значение |
| --- | --- |
| Сервер | Node.js 22+, Express |
| Хранение | SQLite / Firebase Firestore |
| Авторизация | Firebase Auth / Google OAuth, HttpOnly cookie |
| Интерфейс | HTML, CSS, JavaScript; адаптивная верстка |
| Размер вложения | До 2 МБ; до 4 файлов в сообщении |
| Документы | Извлечение текста; PDF — первые 12 страниц, до 50 000 символов |
| Защита | CSP, очистка Markdown, ограничения запросов и проверка доступа |

Для общего веб-поиска владелец задаёт `TAVILY_API_KEY` в Environment (либо существующий `BRAVE_SEARCH_API_KEY`). Чтение страниц по ссылке не требует ключа поиска; страницы с авторизацией, CAPTCHA или обязательным JavaScript не поддерживаются.

Качество и доступность ответов зависят от выбранной модели, лимитов и работы провайдера. Для PDF-сканов без текста страницы нужно прикреплять как изображения. Аудиодорожка видео и старые форматы Office не анализируются; видео обрабатывается по выбранным кадрам, как описано ниже.

ZIP: до 100 элементов и 8 МБ после распаковки. Анализируется текст и код; изображения из архива нужно прикреплять отдельно. Архив для скачивания нормализуется: приватные файлы и зависимости исключаются, PDF/DOCX заменяются извлечённым текстом. Созданный код не исполняется сервером.

**Pongy Plus:** исходный экран тарифа сохранён. Оплата временно отключена — приложение не принимает деньги и не активирует подписку по нажатию кнопки.

## Установка

Установите Node.js 22+ и скачайте проект.

```bash
npm ci
cp .env.example .env
```

В Windows используйте `copy .env.example .env`. Заполните серверные переменные и запустите:

```bash
npm start
```

Для Render: команда сборки `npm ci`, запуска — `npm start`. Переменные задаются в **Environment**, не в GitHub.

Адаптирован для актуальных Chrome, Edge, Firefox и Safari и мобильных экранов. В старых браузерах отдельные возможности могут быть недоступны.

**Pongy AI — понятное управление и ничего лишнего между вами и диалогом.**

## Локальная история

Текст чатов дополнительно сохраняется в IndexedDB этого браузера, отдельно для каждого аккаунта. После очистки серверной базы история восстанавливается с устройства после входа с той же почтой. Firestore и постоянный диск для локальной истории не нужны. В настройках доступны экспорт и импорт JSON-копии; сами вложенные файлы сохраняйте отдельно. Очистка данных браузера удаляет локальную базу.

История обновлений: [CHANGELOG.md](CHANGELOG.md). Заметки релизов: [RELEASES.md](RELEASES.md). Версия **2.0.0 — Глобальный релиз** пока только тизер, не текущий выпуск.


Платные модели и платная генерация изображений отключены на сервере, пока Plus не активен, в том числе при старых флагах IMAGE_GENERATION_ENABLED/IMAGE_MODEL. Бесплатный внешний генератор в этой версии не подключён. Поиск настоящих фотографий Wikimedia — отдельная функция, не генерация. Защита многоуровневая, но не гарантирует отсутствие всех обходов.

### Видео и хранение
Видео MP4/WebM до 20 МБ и 2 минут обрабатывается в браузере: до 9 моментов собираются в три листа с временными метками и передаются доступной бесплатной vision-модели. Очень короткие клипы дают 3 момента. Это не непрерывный анализ и не распознавание звука; краткие события могут быть пропущены. Большой оригинал видео не отправляется на сервер. Качество зависит от разрешения и выбранной модели, а доступность — от квоты провайдера.

Локальные чаты хранятся в IndexedDB этого браузера отдельно для каждого аккаунта и объединяются с серверной историей. Очистка данных сайта, приватный режим, смена браузера или устройства могут удалить/скрыть локальную копию. Используйте экспорт и, при необходимости, облачную синхронизацию. Восстановление локального интерфейса не заменяет серверную проверку сессии и не продлевает истёкшую авторизацию.

### Инструменты и взаимодействие
Кнопка «+» открывает загрузку файлов, режим программирования и генерацию изображений. На узком экране доступны отдельные пункты камеры, галереи и файлов; фактический системный выбор зависит от браузера и ОС. Режим генерации не включает провайдера автоматически и не делает платную генерацию бесплатной.

Последнее применённое действие ИИ можно вернуть запросом «Верни обратно»; обратное действие тоже требует подтверждения. История такого действия хранится отдельно для каждого аккаунта на устройстве. Это не произвольная отмена любых изменений сайта.

Роль разработчика определяется сервером только для подтверждённых публичных адресов команды. Она не отменяет защиту, не открывает чужие чаты и не предоставляет административный доступ. По явному запросу доступна базовая проверка конфигурации, идентичности, защитного фильтра и отмены действий — без выполнения произвольного кода, вызова платного провайдера или заявления о полном тестировании ИИ.

Почтовый контакт поддержки предлагает основной и резервные адреса. Сайт не определяет доставку писем из внешнего почтового приложения и не обещает автоматическое переключение после недоставки.

Резервный движок Vosk выполняется в отдельном worker на устройстве. Аудио в этом режиме не отправляется на сервер. При доступном SpeechRecognition сначала используется движок браузера; политика обработки аудио у него зависит от браузера. При сетевом сбое включается Vosk и запоминается для последующих запусков.

Повторная регистрация занятого адреса отклоняется; существующий вход и восстановление пароля сохраняются. При переходе старого аккаунта на Firebase допускается подтверждённое связывание с тем же аккаунтом, а не создание второго.

### Лимиты сообщений
На аккаунт доступно 100 принятых отправок за сутки UTC. Один чат вмещает до 1000 сообщений пользователя и ИИ суммарно. Второе одинаковое сообщение подряд получает напоминание; третье и последующие помечаются как неотправленные. Вложения участвуют в сравнении. Счётчики хранятся в серверной SQLite; постоянный диск необходим, чтобы они переживали пересоздание сервиса. При нескольких независимых экземплярах сервера нужна общая атомарная база счётчиков. Локальная история не заменяет серверный контроль лимита.

По явной просьбе ИИ может прочитать другой сохранённый чат этого же аккаунта. Названия сравниваются без учёта регистра; неоднозначный выбор требует уточнения. Вложения не входят в текст чтения. Большие чаты могут не помещаться в контекст целиком; модель получает явный признак неполноты и не должна утверждать обратное.

Навыки меню «+» показываются метками в начале поля ввода и не входят в текст запроса. Крестик доступен при наведении и фокусе, а на сенсорном экране виден постоянно. Удаление метки не удаляет прикреплённые файлы.

## Optional APILayer resources
Disabled by default (`APILAYER_ENABLED=false`). Enable only after confirming the product subscriptions, HTTPS access and quota in the provider dashboard. Set credentials only in the server environment: a product-specific `APILAYER_<PRODUCT>_KEY` overrides `APILAYER_API_KEY`. A Marketplace API key is not assumed to work with the direct product APIs used here. No arbitrary endpoint overrides, HTTP downgrade, automated retries or paid fallback are implemented.

| Product | Integration scope | Cache |
| --- | --- | --- |
| Mediastack | Published news, up to 5 records | 15 minutes |
| Numverify | Phone formatting/country/carrier metadata; not ownership or reachability | 24 hours, account-scoped memory only |
| IPstack | Approximate location of an explicitly supplied public IP; no automatic IP profiling | 24 hours, account-scoped memory only |
| Aviationstack | Flight status by flight code, airline reference by IATA code | 5 minutes |
| Positionstack | Forward/reverse geocoding of an explicitly supplied address/coordinates; no map tiles or routing | 30 days, account-scoped memory only |
| Countrylayer | Country reference by ISO alpha-2 code; offsets may not reflect current daylight saving | 7 days |
| Marketstack | Up to 5 historical/end-of-day stock records; not live quotes, forex or investment advice | 1 hour |
| Mailboxlayer | Syntax and domain/MX signals; SMTP and catch-all checks disabled, no guaranteed mailbox existence/delivery | 6 hours, account-scoped memory only |

Queries are offered to the model only for relevant explicit requests. They are not mandatory, even when a tool is offered. A phone/email/address/IP must come from the current request, not account settings, server network metadata or earlier chats. Removing an instruction to use external services prevents offering these tools. At most two different specialized products can be used in one answer; a product is not retried in that answer. The provider receives only the needed lookup arguments, not the whole conversation. Data and timestamps are reference material, never governing instructions. Sources are added to the standard source list.

`APILAYER_MONTHLY_LIMIT` is capped at 100 per product **for all users combined**; lower it to reserve quota for other applications. SQLite atomically reserves requests before sending; failed HTTP calls, malformed replies and timeouts count conservatively. Identical concurrent lookups are coalesced. Valid cache hits do not consume requests. The cap also covers a rolling 31-day window, so crossing a calendar month cannot create an accidental burst above a free allowance. This is stricter than some provider billing cycles. Limits do not include other applications using the same key: inspect actual provider usage and lower the local cap accordingly. This integration does not enable paid plans or configure the provider's billing/overage settings.

Quota and public-cache tables use the server SQLite file and require a persistent disk to survive service recreation. Separate server instances with independent databases do not share quotas; use one instance or implement shared atomic quota storage before scaling. Do not delete the database to reset limits. Failed authorization/plan checks open a protective circuit; a changed key changes that circuit identity. A provider quota response blocks that credential/product for 31 days. Errors are never returned with raw provider bodies or keys. Personal lookup responses are not persisted to the public cache or request-count tables.

## Release integrity

`npm run check` validates project syntax, required files, npm script targets and local server dependencies. `npm run check:release` additionally verifies the original complete release against `MANIFEST.sha256`; intentional source edits invalidate that release snapshot. Neither command proves the absence of all bugs or secrets.

## Storage security boundaries

Browser history is stored locally without a separate encryption password. A returning workspace may display that device’s cached history while the server is unavailable; this does not authorize API access or sending messages. Use a separate browser profile on shared devices and sign out before handing the device to someone else.

The 50 MB aggregate attachment cap currently applies to SQLite storage. Firestore enforces a per-document bound, but this release does not provide a trusted atomic aggregate attachment quota across multiple server instances or direct authenticated Firestore clients. Monitor cloud storage usage; do not interpret the local cap as a cloud billing guarantee.

Cloud deletion reconciliation between separate devices remains limited: a stale local copy on another device can be re-uploaded after a server-side deletion. This release does not claim global deletion consistency.

## Ответы и доступность

Простые числовые выражения с арифметическими действиями, скобками и небольшими целыми степенями вычисляются локально точными дробями, без внешней модели. Это не универсальный решатель уравнений, геометрии или текстовых задач. Разговорный стиль и сленг учитываются в инструкциях модели; поддержка всех языков и безошибочность ответов не гарантируются.

Фотографии сохраняются с большей детализацией; видео по-прежнему анализируется по 3–9 выбранным кадрам без звука, а не непрерывно. Недоступность бесплатных провайдеров, их квоты и ограничения аккаунта не могут быть устранены интерфейсом. В журнале сервера указывается безопасная категория отказа без текста запроса и секретов.

Без платёжного провайдера доступны выбор метода и финальное подтверждение; сообщение о недоступности появляется после нажатия «Оплатить». Реквизиты карты не собираются, фиктивные QR-коды не создаются, платная подписка не начисляется. Рабочий защищённый checkout и QR требуют интеграции реального эквайринга и серверного подтверждения платежа.

Анимации учитывают системную настройку уменьшения движения. При включённом reduced motion блики и подпрыгивания намеренно отключены.

## Голос, движение и версии интерфейса

При недоступном браузерном сервисе или отсутствии SpeechRecognition автоматически используется Vosk Browser с комплектными моделями RU/EN. При первом запуске загружается примерно 45 МБ для русского или 40 МБ для английского. Дождитесь статуса «Слушаю на устройстве»; затем говорите. Модель переиспользуется в текущей вкладке, а архив может оставаться в HTTP-кеше браузера. Декомпрессия и распознавание выполняются в памяти, без обязательного IndexedDB и сторонних речевых API. Для смены языка используется настройка языка сайта. Нужны HTTPS (или localhost), разрешение микрофона, WebAssembly, Worker и Web Audio. Скорость и точность зависят от устройства, микрофона и речи; работа на всех устройствах не гарантируется.

Все шесть `public/speech-models/*.part*` обязательны: сервер объединяет их в два потоковых архива по фиксированным URL. Каждый файл меньше 25 МБ для загрузки через GitHub. Никаких ключей речевого API или новых переменных Render не требуется. Основная страница сохраняет строгий CSP без string evaluation; динамические Embind-привязки разрешены только изолированному статическому речевому worker с доступом к пути моделей.

Сайт 0.16.0 совместим с нативными онлайн-клиентами 0.15.0: установщики не менялись, переустановка не требуется. Слоган «Приложение на личном устройстве может работать быстрее» относится к возможному поведению интерфейса, а не к измеренному ускорению серверной модели.

Настройка «Анимации» хранится на текущем устройстве. По умолчанию соблюдается системное уменьшение движения. «Плавные анимации» — явный выбор пользователя, включающий блики и точки; «Уменьшить движение» отключает движение.

Кнопка со стрелкой вниз появляется, когда последнее сообщение осталось ниже области просмотра. Она расположена внутри области чата над полем ввода и возвращает к последнему сообщению. Основные CSS/JS имеют номер сборки; несовпадение версии интерфейса, CSS и API показывается отдельным уведомлением без автоматической перезагрузки.

## Бесплатные ответы и маршрутизация 0.12.0

Встроенные списки кандидатов различаются для обычных вопросов, программирования и сложных математических задач. Кандидаты проходят проверку текущего каталога: только `:free` или `openrouter/free`, с нулевыми ценами ввода, вывода и всех дополнительных полей цены. Недоступные по контексту, vision или временной блокировке модели исключаются. В запросах дополнительно установлен нулевой предел стоимости токенов. Платного резерва нет; Plus не активен.

Один ответ использует максимум восемь последовательных моделей: основную и до семи резервных, включая бесплатный маршрутизатор. Короткие ошибки переключают сразу; ожидание первого текста или вызова инструмента ограничено шестью секундами для обычных вопросов и восемью для кода/сложных задач. Общий срок обработки остаётся ограниченным 75 секундами. Это не обещание времени готового ответа: квоты, холодный запуск и доступность внешнего провайдера сохраняются. Пустые heartbeat-события не продлевают ожидание.

Точные короткие приветствия обрабатываются локально с учётом сохранённого имени и подтверждённой сервером роли разработчика, после проверок сессии, безопасности и лимитов. Контекстные реплики вроде «поч?» передаются модели вместе с недавним разговором: они не заменяются словарным определением. Подсказки по разговорной речи RU/EN не являются обучением модели, полной словарной базой или гарантией качества всех языков.

Запрошенные ссылки разрешены в тексте ответа; реальные источники, файлы и изображения также показываются отдельными карточками после успешных инструментов. Формулы, списки, выделение и блоки кода остаются безопасно отформатированными. Ответ, оборванный лимитом токенов, не объявляется завершённым и не превращается автоматически в якобы полный файл.

Приоритеты являются инженерным выбором среди доступных бесплатных кандидатов, а не утверждением первого места во всех независимых тестах. Каталоги и условия провайдеров меняются; качество, отсутствие ошибок и постоянная доступность не гарантируются.

## Контекст и команды 0.12.2

ИИ получает текущие значения темы, языка, имени, поиска, рассуждения, выбранного интерфейсного режима модели, анимаций, памяти и состояния встроенной музыки. Текущий интерфейс передаёт несекретный снимок состояния; почта, подтверждение адреса, статус разработчика, подписка и дата аккаунта берутся только из проверенной сервером записи. Сведения об аккаунте включаются при соответствующем вопросе, а не отправляются модели при каждом сообщении. Число чатов относится к сохранённым серверным чатам этого аккаунта; несинхронизированные локальные копии туда не входят. Исходная дата Firebase предпочтительнее даты локальной записи; неизвестная дата не выдумывается.

Повторная просьба установить уже выбранную тему/язык/параметр не создаёт предложение изменения. Вызовы инструмента дополнительно проверяются на соответствие просьбе; перед подтверждением интерфейс повторно проверяет актуальное значение. Доступны предложения изменить тему, язык, имя, контекст других чатов, анимации, поиск, рассуждение, открыть свой чат, создать новый и управлять встроенным эмбиентом. Это ограниченный список команд, не произвольное управление браузером, устройством, платежами или защитой. Все реальные изменения требуют кнопки «Применить».

Явно запрошенный сохранённый чат читается только в пределах текущего аккаунта. Заголовки и текст остаются справочными данными, не инструкциями для выполнения действий. Большой чат может быть усечён; признак неполноты сохраняется. Вложения этим инструментом не читаются.

Язык ответа уточняется по текущему вопросу, явной просьбе и контексту коротких реплик; иностранная цитата не должна переключать язык всей беседы. Проверенные сведения о настройках и аккаунте могут возвращаться локально без модели. Соблюдение языка произвольными внешними моделями не гарантируется.

Защита проверяет известные замаскированные запросы, ограниченно разворачивает вложенные кодировки и независимо проверяет генерируемые блоки кода до завершения ответа/создания файлов. Роли и разрешения не берутся из текста пользователя или интерфейсных подсказок. Фильтры не являются доказательством невозможности всех смысловых обходов.

Метки времени новых сообщений сохраняются с историей; старые сообщения без даты помечаются без выдуманного времени. Тема и переводы интерфейса применяются одним кадром, а анимации учитывают системное предпочтение уменьшения движения.

## Вложения и сведения о тарифе

На входе принимается одно фото до 25 МБ или видео до 100 МБ. Фото оптимизируется перед анализом; большой оригинал видео не загружается в облачную базу: для клипов до 2 минут сохраняются три листа с выборкой кадров и временными метками. Звук видео не анализируется. Прочие файлы — до 2 МБ, текст — до 100000 символов. Обычных вложений до четырёх, видео занимает 3–4 места. Карточка появляется сразу с локальным предпросмотром и круговым индикатором; отправка становится доступна после успешной загрузки. Индикатор отражает фактическую передачу, а не выдуманную скорость обработки. На сервере большие фото временно записываются в закрытый каталог, декодируются последовательно и удаляются после запроса.

Сведения о текущих лимитах и недоступной оплате Plus доступны без вызова внешней модели. Лимит сайта — 100 пользовательских сообщений за день UTC и 1000 сообщений с ответами в чате. У провайдера отдельные ограничения: резервные бесплатные модели, короткий ограниченный повтор и общий cooldown не снимают суточную квоту и не гарантируют 100 облачных ответов.
