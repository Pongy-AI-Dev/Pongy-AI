# Проверка полного комплекта 0.6.7

Проверено на Node.js 22 после чистого `npm ci`:

- `npm run check`: успешно.
- `npm test`: 111 тестов, 0 ошибок, 0 пропусков.
- Chromium: все 6 UI-наборов, 153 проверки.
- Firefox: все 6 UI-наборов, 153 проверки.
- `npm audit --omit=dev`: известных уязвимостей не обнаружено на момент проверки. Это не гарантия отсутствия любых уязвимостей.

В Chromium проверен режим CI=true с заведомо неверным CHROMIUM_PATH: используется установленный браузер Playwright, а не этот путь.

Повторный прогон обнаружил гонку в тесте сохранения истории: завершение вывода ответа не означает завершение HTTP-записи. Теперь тест ждёт фактическую запись в SQLite до 5 секунд и по-прежнему падает, если запись не появилась.

Firefox ранее зависал на нативном запросе navigator.storage.persist(). Интерфейс теперь показывает ожидание и ограничивает время ожидания; UI-тесты отдельно воспроизводят разрешение, отказ и отсутствие ответа.

WebKit не прошёл полноценную локальную проверку из-за несовместимости среды выполнения. Нельзя считать его подтверждённо рабочим по этим результатам. В GitHub Actions сохранён отдельный запуск WebKit на Ubuntu 24.04 с установкой браузера и его зависимостей. Проверять нужно результат последнего коммита после загрузки полного комплекта.

Реальные Google OAuth, почта, модели ИИ и поисковые провайдеры с пользовательскими ключами не проверялись: UI-тесты используют локальные фикстуры. Оплата остаётся заглушкой. Отсутствие абсолютно всех ошибок не гарантируется.
